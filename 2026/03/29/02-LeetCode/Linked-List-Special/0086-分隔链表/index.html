0086. 分隔链表 - 双虚拟头结点技巧与断链陷阱详解

本文深入分析LeetCode第86题”分隔链表”，重点讲解双虚拟头结点技巧和”断链陷阱”的避免方法，这是链表操作中容易出错的关键点。

题目描述

英文题目

Partition List

中文题目

给你一个链表的头节点 head 和一个特定值 x ，请你对链表进行分隔，使得所有 小于 x 的节点都出现在 大于或等于 x 的节点之前。

你应当 保留 两个分区中每个节点的初始相对位置。

示例

约束条件

  • 链表中节点的数目在范围 [0, 200] 内
  • -100 <= Node.val <= 100
  • -200 <= x <= 200

解题思路

核心思想

使用两个虚拟头结点分别构建小于x的链表和大于等于x的链表，最后将两个链表连接起来。

关键技巧

  1. 双虚拟头结点：简化边界处理
  2. 断链操作：移动节点时必须断开原连接
  3. 保持相对位置：按原顺序遍历，自然保持相对位置

算法步骤

  1. 创建两个虚拟头结点：dummy1（小于x），dummy2（大于等于x）
  2. 创建两个指针：p1指向dummy1，p2指向dummy2
  3. 遍历原链表：
    • 如果curr.val < x：连接到p1链表
    • 否则：连接到p2链表
  4. 连接两个链表：p1.next = dummy2.next
  5. 断开尾节点：p2.next = None
  6. 返回dummy1.next

正确断链操作

保持相对位置

由于是按原顺序遍历，自然保持了相对位置：

  • 小于x的节点按原顺序连接
  • 大于等于x的节点按原顺序连接
  • 最后连接两个链表，保持整体相对位置

1. 空链表

2. 所有节点都小于x

3. 所有节点都大于等于x

4. 单个节点

性能分析

时间复杂度

  • 遍历链表：O(n)，每个节点访问一次
  • 连接操作：O(1)
  • 总计：O(n)

空间复杂度

  • 虚拟头结点：O(1)，常数空间
  • 指针变量：O(1)
  • 总计：O(1)
