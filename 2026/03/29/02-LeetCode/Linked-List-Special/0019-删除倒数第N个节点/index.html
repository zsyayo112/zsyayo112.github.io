0019. 删除倒数第N个节点 - 快慢指针与虚拟头结点技巧详解

本文深入分析LeetCode第19题”删除倒数第N个节点”，重点讲解快慢指针技巧和虚拟头结点在处理边界条件时的关键作用。

题目描述

英文题目

Remove Nth Node From End of List

中文题目

给你一个链表，删除链表的倒数第 n 个结点，并且返回链表的头结点。

示例

进阶

你能尝试使用一趟扫描实现吗？

约束条件

  • 链表中结点的数目为 sz
  • 1 <= sz <= 30
  • 0 <= Node.val <= 100
  • 1 <= n <= sz

解题思路

核心思想

使用快慢指针技巧，让快指针先走n步，然后快慢指针同步前进，当快指针到达链表末尾时，慢指针正好指向要删除节点的前一个节点。

关键技巧

  1. 虚拟头结点(dummy node)：处理删除头结点的特殊情况
  2. 快慢指针：一趟扫描找到倒数第n个节点
  3. 步长控制：快指针先走n+1步（因为要找到前驱节点）

算法步骤

  1. 创建虚拟头结点 dummy，连接到原链表
  2. 初始化快慢指针都指向 dummy
  3. 快指针先向前移动 n+1 步
  4. 快慢指针同步向前移动，直到快指针为 None
  5. 此时慢指针指向要删除节点的前一个节点
  6. 执行删除：slow.next = slow.next.next
  7. 返回 dummy.next

步数为什么是n+1？

因为我们要找到的是要删除节点的前一个节点，而不是要删除的节点本身。

边界条件处理

1. 删除头结点 (n == 链表长度)

2. 删除尾结点 (n == 1)

3. 链表只有一个节点

4. n等于链表长度-1

常见错误

错误1：步数错误（走n步而不是n+1步）

错误2：忘记虚拟头结点（删除头结点出错）

错误3：循环条件错误

错误4：未检查n的有效性

性能分析

时间复杂度对比

方法 时间复杂度 扫描次数 优点 缺点
快慢指针+虚拟头结点 O(L) 1趟 最优，一趟扫描 需要理解指针步数
两趟扫描 O(2L) = O(L) 2趟 逻辑简单 需要两次遍历
栈方法 O(L) 1趟（但需要额外空间） 容易理解 空间复杂度O(L)

空间复杂度对比

方法 空间复杂度 说明
快慢指针+虚拟头结点 O(1) 只使用常数额外空间
两趟扫描 O(1) 只使用常数额外空间
栈方法 O(L) 需要栈存储所有节点

实际性能考虑

  • 链表长度小(L<100)：所有方法性能差异不大
  • 链表长度大：一趟扫描方法有明显优势
  • 内存限制严格：避免栈方法
