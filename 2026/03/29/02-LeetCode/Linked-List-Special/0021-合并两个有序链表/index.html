0021. 合并两个有序链表 - 虚拟头结点技巧详解

本文详细分析LeetCode第21题”合并两个有序链表”，通过虚拟头结点技巧，实现简洁高效的链表合并算法。

题目描述

英文题目

Merge Two Sorted Lists

中文题目

将两个升序链表合并为一个新的升序链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

示例

约束条件

  • 两个链表的节点数目范围是 [0, 50]
  • -100 <= Node.val <= 100
  • l1 和 l2 均按 非递减顺序 排列

解题思路

核心思想

使用**虚拟头结点(dummy node)**技巧，避免对空链表的特殊处理，统一合并逻辑。

算法步骤

  1. 创建虚拟头结点 dummy
  2. 使用指针 curr 指向当前合并位置
  3. 比较两个链表当前节点的值，将较小的连接到 curr.next
  4. 移动相应链表的指针
  5. 重复步骤3-4直到某个链表为空
  6. 将非空链表的剩余部分连接到结果链表
  7. 返回 dummy.next

时间复杂度

  • 时间复杂度：O(n + m)，其中 n 和 m 分别是两个链表的长度
  • 空间复杂度：O(1)，只使用了常数级别的额外空间
