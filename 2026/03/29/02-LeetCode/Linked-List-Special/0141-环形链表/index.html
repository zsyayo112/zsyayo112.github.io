0141. 环形链表 - 快慢指针检测环与Floyd判圈算法详解

本文深入分析LeetCode第141题”环形链表”，详细讲解Floyd判圈算法（快慢指针）的原理、证明和实现，这是链表算法中的经典问题。

题目描述

英文题目

Linked List Cycle

中文题目

给你一个链表的头节点 head ，判断链表中是否有环。

如果链表中有某个节点，可以通过连续跟踪 next 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测系统内部使用整数 pos 来表示链表尾连接到链表中的位置（索引从 0 开始）。注意：pos 不作为参数进行传递。仅仅是为了标识链表的实际情况。

如果链表中存在环，则返回 true 。否则，返回 false 。

示例

进阶

你能用 O(1)（即，常量）内存解决此问题吗？

约束条件

  • 链表中节点的数目范围是 [0, 10^4]
  • -10^5 <= Node.val <= 10^5
  • pos 为 -1 或者链表中的一个有效索引

解题思路

核心思想

使用Floyd判圈算法（快慢指针）：

  • 慢指针 slow 每次走1步
  • 快指针 fast 每次走2步
  • 如果链表中有环，快慢指针一定会相遇
  • 如果链表中无环，快指针会先到达末尾

算法原理（Floyd’s Cycle Detection Algorithm）

  1. 初始化：slow = fast = head
  2. 移动指针：
    • 慢指针每次移动1步：slow = slow.next
    • 快指针每次移动2步：fast = fast.next.next
  3. 检测相遇：
    • 如果 fast == slow，说明有环
    • 如果 fast 或 fast.next 为 None，说明无环

Floyd算法数学证明

为什么快慢指针一定会相遇？

设：

  • 环外部分长度为 L（从头结点到环入口）
  • 环的周长为 C
  • 相遇时慢指针走了 k 步
  • 快指针走了 2k 步

情况分析：

  1. 慢指针进入环时：

    • 慢指针走了 L 步进入环
    • 快指针走了 2L 步，已经在环中走了 L 步
    • 快指针在环中领先慢指针 L 步

  2. 在环中追击：

    • 快指针每次比慢指针多走1步
    • 快指针需要追赶上慢指针的领先距离
    • 由于在环中，领先距离可以视为 C - (L mod C)
    • 快指针需要 C - (L mod C) 步追上慢指针

  3. 总步数：

    • 慢指针总步数：L + [C - (L mod C)] < L + C
    • 快指针总步数：2L + 2[C - (L mod C)] < 2L + 2C
    • 由于 L < 10^4, C < 10^4，总步数有限，一定会相遇

方法 时间复杂度 最坏情况 平均情况 优点 缺点

方法 空间复杂度 说明

实际性能考虑

  • 链表长度小：所有方法性能差异不大
  • 链表长度大且有环：快慢指针最优
  • 链表长度大且无环：快慢指针和哈希表相当
  • 内存限制严格：必须使用快慢指针
