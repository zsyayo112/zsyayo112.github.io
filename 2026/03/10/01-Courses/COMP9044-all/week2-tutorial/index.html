1. sort -排序

sort : 不仅仅是排序， 关键在于 -k(key) 定位字段和 -n(numeric)按排序排

选项 含义 示例
-k F,F(F表示 Field， 字段) 按第 F 个字段排序 sort -k2,2
-t ‘SEP’ 按照指定分隔符排序 sort -t ‘
-n 数值排序(非字典序) sort -k3,3n
-r 逆序排序 sort -k2,2r
-k F.c 从第F个字段的第c个字符开始 -k1.8,1n

多键排序

sort -k3,3 -k2,2 benchmarks

⚠️ -k2,2 和 -k2 的区别：-k2 表示”从第2字段到行尾”，-k2,2 才表示”仅第2字段”。做精确排序时要加结束列号!

5. sed - 流编辑器

命令 用法
s/PATTERN/REPLACEMENT/ 替换(1次)
s/PATTERN/REPLACEMENT/g 替换(全行)
/PATTERN/d 删除
/START/,/END/d 删除从 START 到 END 的行范围
-E 使用扩展正则
\t Tab字符（在模式中）

⚠️ \b 是单词边界，确保 program2 不会误匹配 program20。

sed -n

这是个非常关键的参数。简单来说，-n 的作用是**“关掉 sed 的大喇叭”**。

  1. 默认情况：Sed 是个“复读机”默认情况下，sed 每读入一行，处理完之后无论有没有修改，都会把这一行自动打印出来。Bash# 即使你什么都不做，它也会把整个文件原样打出来
    sed ‘’ data.txt

  2. 加入 -n：Sed 变成“沉默者”当你加上 -n（全称 –quiet 或 –silent）时，sed 进入静默模式。它依然会读取每一行，但除非你明确命令它打印，否则它什么都不会输出。Bash# 什么都不会显示，因为没有打印指令
    sed -n ‘’ data.txt

  3. -n 必须配合 p 指令使用在静默模式下，我们通常使用 p (print) 指令来告诉 sed：“只有符合这个条件的行，才给我印出来！” 这就是为什么打印第 3 到 7 行要写成：Bashsed -n ‘3,7p’ data.txt. -n：先闭嘴，不要默认打印所有行。 3,7：找到第 3 到第 7 行。p：把这几行印出来。

  4. 如果不加 -n 会发生什么？如果你只写 sed ‘3,7p’ data.txt（没加 -n），结果会让你大吃一惊：第 1 行：不是 3-7，默认打印一次。第 2 行：不是 3-7，默认打印一次。第 3 行：属于 3-7，执行 p 指令打印一次，然后 sed 默认又打印一次（这行会出现两次！）。…以此类推。

结果如下：Plaintextline1
line2
line3 <– p 指令印的
line3 <– 默认印的
line4
line4
…
💡 形象的比喻普通 sed：像个复读机，不管改没改，每行都得喊一遍。sed -n：像个狙击手，潜伏在那不动，只有看到目标（匹配到模式）并接到指令（p）时才开火（打印）。常见用法总结命令含义sed -n ‘5p’只打印第 5 行sed -n ‘$p’只打印最后一行sed -n ‘/error/p’只打印包含 “error” 关键字的行（类似 grep）

我们要把它们分成两大阵营：一个是运行 sed 的外部开关，另外两个是写在引号里的内部指令。

  1. 外部开关：-i (In-place)它是 sed 命令的一个选项，写在引号外面。
    它的作用只有一个：直接修改原文件。
    默认（不加 -i）：sed 只是把处理后的结果印在屏幕上给你看，原文件没有任何变化。
    加了 -i：sed 会悄悄地把修改保存回原文件。[!WARNING]小心： 在 macOS 上，必须写成 sed -i ‘’ ‘…’（多一个空引号）。

  2. 内部指令：a 和 i这两个是写在引号里的动作指令，用来在文件的特定位置增加新行。
    a (Append) —— 在“后”加逻辑：在匹配到的行之后插入新内容。口诀：After（在……之后）。
    i (Insert) —— 在“前”加逻辑：在匹配到的行之前插入新内容。口诀：In front of（在……前面）。

  3. 三者对比表符号身份作用位置例子-i选项 (Option)保存到文件引号外面sed -i ‘…’ filea指令 (Command)在行后追加引号内面sed ‘2a\Hello’ filei指令 (Command)在行前插入引号内面sed ‘2i\Hello’ file

符号,身份,作用,位置,例子
-i,选项 (Option),保存到文件,引号外面,sed -i ‘…’ file
a,指令 (Command),在行后追加,引号内面,sed ‘2a\Hello’ file
i,指令 (Command),在行前插入,引号内面,sed ‘2i\Hello’ file

练习 5-B

写sed命令: 删除文件中所有空行

  1. 为什么 \s 在 sed 里可能失效？
    sed 主要分为两个流派，它们对 \s 的支持完全不同：

    GNU sed (Linux/WSL2)： 通常支持 \s 匹配空格或 Tab。

    BSD sed (macOS)： 不支持 \s。如果你在 Mac 的终端写 sed ‘s/\s//g’，它可能根本不理你，或者把你文本里的字母 s 给删了。

    更稳妥的写法：
    为了保证在任何机器上都能运行，大家习惯用 [[:space:]]，它等价于 \s（匹配空格、制表符、换页符等）。

  2. \s 能代表“空行”吗？
    这是一个常见的误区：\s 代表的是“字符”，而“空行”是“逻辑状态”。

    \s：匹配一个看不见的字符（空格或 Tab）。

    ^$：匹配一个位置（行首紧跟行尾），这才是真正的空行。

    ^\s*$：匹配**“伪空行”**（行内可能包含空格或 Tab，但没有文字）。

  3. tr 命令能用 \s 吗？
    绝对不行。

    tr 是一个非常老派且简单的工具，它不识别复杂的正则缩写（如 \d, \s, \w）。

    ❌ tr -d ‘\s’ (这只会删除字母 s)

    ✅ tr -d ‘[:space:]’ (这才会删除所有空白字符)

总结对比表

表达方式 含义 兼容性 推荐场景
\s 单个空白字符 一般 (GNU 工具支持, BSD 不支持) 快速在 Linux 命令行随手写
[[:space:]] 单个空白字符 极高 (POSIX 标准) 编写正式脚本、跨平台使用
^$ 纯空行 极高 仅删除没有任何内容的行
^[[:space:]]*$ 空行或仅含空格的行 极高 清洗数据最常用的“吸尘器”

6. join - 合并两个有序文件

核心要求 & 用法
⚠️ join 要求两个输入文件都按连接键排好序！

选项 含义
-t ‘SEP’ 指定字段分隔符
-a 1 输出文件1中未匹配的行（左外连接）
-a 2 输出文件2中未匹配的行
-a 1 -a 2 全外连接
-o auto 自动决定输出字段（全外连接时必须）
-e ‘STR’ 缺失字段用 STR 填充

内连接：只输出两门课都有的学生

join -t’|’ comp1511-sorted.psv comp2041-sorted.psv

全外连接：没选某课显示 –

join -t’|’ -a1 -a2 -o auto -e’–’ comp1511-sorted.psv comp2041-sorted.psv

内连接后按1511成绩升序、2041成绩降序排列

join -t’|’ comp1511-sorted.psv comp2041-sorted.psv | sort -t’|’ -k2,2 -k3,3r
