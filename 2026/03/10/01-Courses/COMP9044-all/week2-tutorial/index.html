第二阶段： 核心工具笔记

1. sort -排序

sort : 不仅仅是排序， 关键在于 -k(key) 定位字段和 -n(numeric)按排序排

选项 含义 示例
-k F,F(F表示 Field， 字段) 按第 F 个字段排序 sort -k2,2
-t ‘SEP’ 按照指定分隔符排序 sort -t ‘
-n 数值排序(非字典序) sort -k3,3n
-r 逆序排序 sort -k2,2r
-k F.c 从第F个字段的第c个字符开始 -k1.8,1n

多键排序

sort -k3,3 -k2,2 benchmarks

⚠️ -k2,2 和 -k2 的区别：-k2 表示”从第2字段到行尾”，-k2,2 才表示”仅第2字段”。做精确排序时要加结束列号!

练习1-A
下面的文件是 benchmarks（Tab 分隔），第2列是”第一基准”，第3列是”第二基准”，第4列是”第三基准”。
写命令：先按第三基准排序，再按程序编号（字段1中数字部分）排序。

基准1 基准2 基准3 基准4
program1 08 03 05
program10 09 04 16
program2 14 03 05

参考答案

-k1.8,1n 表示从第1个字段的第8个字符(“Program”后面的数字开始)， 按照数值排序。 这样Program2就排在Program10的前面了

3. tr - 字符转换 /删除 / 压缩

核心用法

选项 含义
tr ‘A’ ‘B’ 把字符集A中的字符替换为B中对应字符
-d ‘SET’ 删除 SET 中的字符
-c ‘SET’ 取补集（SET 以外的所有字符）
-s ‘SET’ 压缩（squeeze）连续重复字符为一个
[:alpha:] 所有字母（等同 a-zA-Z）
[:alnum:] 所有字母+数字
[:lower:] / [:upper:] 小写 / 大写字母

经典技巧

解析: -c 取补集， 把所有的非字母数字字符替换为 \n ; -s 压缩连续换行， 每行一个词

场景设定： 你拿到了一个名为 raw_data.txt 的原始文件，内容如下（包含脏数据）：

学号 课程 分数 日期
z5523839 COMP9044 85 2026-03-01
z1234567 MATH1131 45 2026-02-15
z9876543 comp9044 92 2026-03-05
z5523839 COMP9417 78 2026-03-02
z1111111 ENGG1000 06 2026-01-20
BAD_DATA WRONG123 XX 2026-00-00
z2222222 COMP9044 59 2026-03-10

第二部分：管道与过滤器 (Week 02)

  1. 字段提取：使用 cut 提取所有的 zID 和分数（第一列和第三列）。注意：分隔符是 |（包含空格）。

  2. 分数排序：

    首先，按 zID 升序排列。

    如果 zID 相同，按分数数字逆序排列。

  3. 统计挂科率：统计所有分数低于 50 的学生人数。

  4. 去重计数：统计这个文件里一共出现了多少门不同的课程（注意大小写统一）。

第三部分：进阶挑战（补全知识点）###

  1. 前导零处理 (Sed)：最后一行 06 分，请用 sed 去掉分数前的 0，变成 6。

  2. 权限检查 (ls -l)：在执行这些操作前，你需要确保 raw_data.txt 对你（Owner）是可读写的，但对其他人（Others）是不可见的。请写出修改权限的命令。
