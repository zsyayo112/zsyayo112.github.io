滑动窗口算法：通用框架与实战指南

滑动窗口是解决子串、子数组问题的利器。本文总结滑动窗口的通用解题框架，涵盖三种常见变体、关键技巧和实战题目，帮助你系统掌握这一重要算法。

算法核心思想

滑动窗口算法用于解决数组/字符串的子区间问题，通过维护一个窗口（连续区间），在遍历过程中动态调整窗口的左右边界。

核心特点：

  • 使用双指针 left 和 right 表示窗口边界
  • right 向右移动扩大窗口，寻找可行解
  • left 向右移动缩小窗口，优化解或寻找新解
  • 时间复杂度通常为 O(n)，空间复杂度 O(1) 或 O(k)

适用场景

1. 字符串问题

  • 寻找满足条件的子串（最小覆盖、排列、异位词）
  • 最长无重复字符子串
  • 最多包含K个不同字符的最长子串

2. 数组问题

  • 和大于等于目标的最短子数组
  • 乘积小于K的子数组个数
  • 最长连续递增序列

3. 通用特征

  • 问题涉及连续子序列
  • 需要在序列中寻找满足某些条件的最优区间
  • 暴力解法时间复杂度为 O(n²) 或更高

通用模板（Python）

三种常见变体

变体1：固定长度窗口

特点：窗口长度固定，如字符串排列、字母异位词

典型题目：

    1. 字符串的排列
    1. 找到字符串中所有字母异位词

变体2：最小窗口（满足条件的最短子串）

特点：寻找满足条件的最短连续子串

典型题目：

    1. 最小覆盖子串
    1. 长度最小的子数组

变体3：最长无重复子串

特点：窗口内不允许重复字符

典型题目：

    1. 无重复字符的最长子串
    1. 水果成篮（最多包含两种字符的最长子串）

关键技巧与陷阱

技巧1：字典保护（避免 defaultdict 污染）

技巧2：验证逻辑设计

  • valid：窗口中满足条件的字符种类数
  • goal_valid：需要满足的字符种类数（len(need)）
  • 当 valid == goal_valid 时，窗口满足目标条件
  • 注意：goal_valid 是字符种类数，不是字符总数

技巧3：窗口收缩时机

技巧4：指针移动对称性

技巧5：边界情况处理

解题步骤

步骤1：分析问题类型

  1. 是固定长度还是可变长度？

    • 固定长度：窗口大小不变（如字符串排列）
    • 可变长度：窗口大小变化（如最小覆盖子串）

  2. 是找最小窗口、最大窗口还是固定窗口？

    • 最小窗口：满足条件的最短区间
    • 最大窗口：满足条件的最长区间
    • 固定窗口：窗口大小固定

  3. 窗口内需要满足什么条件？

    • 字符频率匹配
    • 无重复字符
    • 和/乘积满足条件

步骤2：设计数据结构

  1. 需要哪些字典/计数器？

    • need：目标字符频率
    • window：窗口字符频率
    • 可能还需要其他辅助变量

  2. 需要哪些验证变量？

    • valid：满足条件的字符种类数
    • goal_valid：需要满足的字符种类数
    • 其他条件变量

  3. 需要记录哪些结果？

    • 最小/最大长度
    • 起始位置
    • 计数结果

步骤3：实现窗口逻辑

  1. 右指针如何移动和更新状态？

    • 获取右指针字符
    • 更新窗口统计
    • 更新验证变量

  2. 什么条件下需要收缩窗口？

    • 根据问题类型设计收缩条件
    • 注意使用正确的比较运算符

  3. 左指针如何移动和更新状态？

    • 获取左指针字符
    • 反向更新窗口统计
    • 反向更新验证变量

  4. 何时更新结果？

    • 在收缩循环内更新
    • 根据问题要求选择更新时机

步骤4：处理边界情况

  1. 空字符串/数组
  2. 目标长度大于源长度
  3. 没有满足条件的结果
  4. 特殊字符集（如只有小写字母）

常见问题与调试

Q1：为什么结果不对？

可能原因：

  1. 字典被污染（未使用 if in 保护）
  2. 收缩条件错误（如使用 >= 而不是 ==）
  3. 验证逻辑错误（valid 和 goal_valid 计算错误）
  4. 指针移动不对称

调试方法：

Q2：为什么超时？

可能原因：

  1. 有多余的循环或不必要的操作
  2. 字典操作效率低
  3. 收缩条件设计不合理

优化方法：

  1. 使用数组代替字典（当字符集有限时）
  2. 减少不必要的字典访问
  3. 优化收缩条件，避免过度收缩

Q3：如何选择数据结构？

推荐选择：

  1. 小写字母问题：使用长度为26的数组 [0] * 26
  2. ASCII字符问题：使用长度为128的数组 [0] * 128
  3. 通用字符问题：使用 defaultdict(int) 或普通字典
  4. 需要快速查找：使用 set 或位运算

总结

滑动窗口算法的核心是：

  1. 两个指针：left 和 right 定义窗口边界
  2. 两个字典：need 记录目标，window 记录窗口
  3. 验证变量：valid 跟踪满足条件的进度
  4. 收缩条件：根据问题定义何时收缩窗口

关键要点：

  • 字典访问要保护，避免污染
  • 收缩时机要精准，避免滞后
  • 指针操作要对称，保持状态一致
  • 边界情况要考虑，确保鲁棒性

掌握这个框架后，大部分滑动窗口问题都可以套用模板解决。关键是理解问题的本质，正确设置收缩条件和验证逻辑。

本文总结于 2026年3月27日，基于多个滑动窗口题目的解题经验。建议按照学习路线逐步练习，从简单到复杂，从固定窗口到可变窗口，最终达到融会贯通的水平。
