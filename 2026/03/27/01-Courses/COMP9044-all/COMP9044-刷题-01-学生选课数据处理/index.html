步骤3：清洗格式（去除多余空格和中间名）

第一个sed：sed 's/^[[:space:]]*//'

  • 删除行首的所有空白字符（空格、制表符等）
  • ^ 表示行首，[[:space:]]* 匹配0个或多个空白字符

第二个sed：sed 's/[[:space:]].*//'

  • 找到第一个空格，删除该空格及其后的所有内容
  • 这样就去掉了中间名和尾部空格

核心知识点详解

1. cut 命令的嵌套使用

  • 当数据中有多种分隔符时，需要多次使用cut
  • 第一次处理主分隔符，第二次处理嵌套分隔符

2. sort -u 的正确使用时机

  • sort -u 等价于 sort | uniq
  • 在Pipeline前期用于基于”学生”去重
  • 在Pipeline后期需谨慎使用，避免误删同名情况

3. 正则表达式清洗

  • [[:space:]] 比 ' ' 更健壮，能匹配空格和制表符
  • .* 匹配任意字符任意次数
  • ^ 锚定行首，确保只删除行首空白

4. 命令替换的简洁写法

  • Shell Pipeline天然支持命令连接
  • 避免不必要的echo和命令替换

题目：统计各课程人数 (Course Enrollment Count)

利用同样的 enrollments.txt 输入，请写一个Pipeline输出：

  • 每门课程的课程代码（如COMP2041）
  • 该课程有多少名学生选修
  • 按人数从高到低排列；如果人数相同，按课程代码字母序排列

期望输出格式：

解题提示：

  1. 先用 cut 提取课程和学号
  2. 使用 sort -u 确保每人每课只算一次
  3. 再 cut 出课程列
  4. 使用 sort | uniq -c 统计每门课出现的次数
  5. 使用 sort -k1,1nr -k2,2 进行多级排序

参考答案：

分步解析：

  1. cut -d'|' -f1,2：提取课程和学号
  2. sort -u：基于”课程+学号”去重
  3. cut -d'|' -f1：只保留课程列
  4. sort | uniq -c：统计每门课出现次数
  5. sort -k1,1nr -k2,2：按计数降序，课程代码升序
  6. awk '{print $2, $1}'：调整输出格式（课程 人数）
