# COMP9044 刷题01 - 学生选课数据处理：Shell Pipeline实战

> 本文记录COMP9044 Shell编程的一道经典题目：从学生选课数据中提取所有学生的First Name（名），并按要求排序和去重。通过这道题，深入掌握Shell Pipeline设计、数据清洗和多级处理技巧。

## 题目背景与目标

### 输入数据格式
未排序的学生选课数据，格式为：
```
课程|学号|姓名(姓, 名 中间名)|班级/学期|性别
```

示例数据 (`enrollments.txt`)：
```
COMP1917|3360379|Costner, Kevin Augustus |13978/1|M
COMP1917|3364562|Carey, Mary |13711/1|M
COMP3311|3383025|Thorpe, Ian Augustus |13978/3|M
COMP2920|3860448|Steenburgen, Mary Nell |13978/3|F
COMP1927|3360582|Neeson, Liam |13711/2|M
COMP3411|3863711|Klum, Heidi June Anne |13978/3|F
COMP3141|3383025|Thorpe, Ian Augustus |13978/3|M
COMP3891|3863711|KLum, Heidi June Anne |13978/3|F
COMP3331|3383025|Thorpe, Ian Augustus |13978/3|M
COMP2041|3860448|Steenburgen, Mary Nell |13978/3|F
COMP2041|3360582|Neeson, Liam |13711/2|M
COMP3311|3711611|Klum, Mary |13978/3|F
COMP3311|3371161|Thorpe, Ian Fredrick |13711/3|M
COMP3331|5122456|Wang, Wei |13978/2|M
COMP3331|5456732|Wang, Wei |13648/3|M
COMP4920|5456732|Wang, Wei |13648/3|M
```

### 目标要求
提取所有学生的 **First Name（名）**，按字母顺序排列。

### 核心约束
1. **人头去重**：同一个学生选多门课，其名字只打印一次
2. **同名保留**：不同学生如果First Name相同，需按人数重复打印
3. **格式清洗**：处理姓名中多余的空格和中间名
4. **排序输出**：按字母顺序输出，每行一个名字

### 期望输出
```
$ ./final_q1.sh <enrollments.txt
Heidi
Ian
Ian
Kevin
Liam
Mary
Mary
Mary
Wei
Wei
```

## 解题思路分析

### 关键难点
1. **数据清洗**：姓名格式不一致，有中间名、多余空格
2. **正确去重**：基于"学生"去重，而不是基于"名字字符串"去重
3. **同名处理**：不同学生的相同名字需要保留

### 解决方案：分步Pipeline设计
一个健壮的Pipeline应该遵循以下步骤：

```
原始数据 → 字段选择 → 人头去重 → 提取名字 → 清洗格式 → 最终排序
```

## 完整Pipeline实现

### 最终解决方案
```bash
#!/bin/bash
# final_q1.sh

cut -d'|' -f2,3 | sort -u | cut -d',' -f2 | sed 's/^[[:space:]]*//' | sed 's/[[:space:]].*//' | sort
```

### 分步解析

#### 步骤1：字段选择 + 人头去重
```bash
cut -d'|' -f2,3 | sort -u
```
- `cut -d'|' -f2,3`：提取第2列（学号）和第3列（姓名）
- `sort -u`：基于"学号+姓名"组合去重，确保每个学生只出现一次

**中间结果示例**：
```
3360379|Costner, Kevin Augustus 
3364562|Carey, Mary 
3383025|Thorpe, Ian Augustus 
3860448|Steenburgen, Mary Nell 
3360582|Neeson, Liam 
3863711|Klum, Heidi June Anne 
3711611|Klum, Mary 
3371161|Thorpe, Ian Fredrick 
5122456|Wang, Wei 
5456732|Wang, Wei 
```

#### 步骤2：提取First Name部分
```bash
cut -d',' -f2
```
- 以逗号分隔，取第二部分（姓, 名 中间名 → 取"名 中间名"）

**中间结果示例**：
```
 Kevin Augustus 
 Mary 
 Ian Augustus 
 Mary Nell 
 Liam 
 Heidi June Anne 
 Mary 
 Ian Fredrick 
 Wei 
 Wei 
```

#### 步骤3：清洗格式（去除多余空格和中间名）
```bash
sed 's/^[[:space:]]*//' | sed 's/[[:space:]].*//'
```

**第一个sed**：`sed 's/^[[:space:]]*//'`
- 删除行首的所有空白字符（空格、制表符等）
- `^` 表示行首，`[[:space:]]*` 匹配0个或多个空白字符

**第二个sed**：`sed 's/[[:space:]].*//'`
- 找到第一个空格，删除该空格及其后的所有内容
- 这样就去掉了中间名和尾部空格

**清洗后结果**：
```
Kevin
Mary
Ian
Mary
Liam
Heidi
Mary
Ian
Wei
Wei
```

#### 步骤4：最终排序
```bash
sort
```
- 按字母顺序排序
- **注意**：不能加 `-u` 参数，否则会删除同名不同人的情况

**最终输出**：
```
Heidi
Ian
Ian
Kevin
Liam
Mary
Mary
Mary
Wei
Wei
```

## 核心知识点详解

### 1. `cut` 命令的嵌套使用
```bash
# 第一次cut：按'|'分隔，取字段2,3
cut -d'|' -f2,3

# 第二次cut：按','分隔，取字段2  
cut -d',' -f2
```
- 当数据中有多种分隔符时，需要多次使用`cut`
- 第一次处理主分隔符，第二次处理嵌套分隔符

### 2. `sort -u` 的正确使用时机
```bash
# 正确：在提取学号+姓名后去重
cut -d'|' -f2,3 | sort -u

# 错误：如果在最后去重，会误删同名不同人
... | sort -u  # 错误！会删除"Ian"的重复
```
- `sort -u` 等价于 `sort | uniq`
- 在Pipeline前期用于基于"学生"去重
- 在Pipeline后期需谨慎使用，避免误删同名情况

### 3. 正则表达式清洗
```bash
# 删除行首空白
sed 's/^[[:space:]]*//'

# 删除第一个空格及其后内容
sed 's/[[:space:]].*//'
```
- `[[:space:]]` 比 `' '` 更健壮，能匹配空格和制表符
- `.*` 匹配任意字符任意次数
- `^` 锚定行首，确保只删除行首空白

### 4. 命令替换的简洁写法
```bash
# 简洁写法（推荐）
command1 | command2 | command3

# 冗余写法（不推荐）
echo $(command1) | command2 | command3
```
- Shell Pipeline天然支持命令连接
- 避免不必要的`echo`和命令替换

## 易错坑点与调试技巧

### 坑点1：PowerShell冲突（Windows环境）
```bash
# 在Git Bash中运行正常
./final_q1.sh < enrollments.txt

# 在PowerShell中可能报错
# 解决方案：使用Git Bash或WSL
```

### 坑点2：过度去重
```bash
# 错误：最后一步加-u会删除同名不同人
... | sort -u  # 错误！

# 正确：只在基于"学生"时去重
cut -d'|' -f2,3 | sort -u  # 正确
```

### 坑点3：空格处理不彻底
```bash
# 可能的问题数据
"Last, First  "    # 尾部双空格
"Last,First"       # 无空格
"Last,  First Mid" # 多个空格

# 健壮的清洗方案
sed 's/^[[:space:]]*//' | sed 's/[[:space:]].*//'
```

### 调试技巧：分步验证
```bash
# 1. 查看原始数据
cat enrollments.txt | head -5

# 2. 验证字段选择
cat enrollments.txt | cut -d'|' -f2,3 | head -5

# 3. 验证去重效果  
cat enrollments.txt | cut -d'|' -f2,3 | sort -u | wc -l

# 4. 验证名字提取
cat enrollments.txt | cut -d'|' -f2,3 | sort -u | cut -d',' -f2 | head -5

# 5. 验证清洗效果
cat enrollments.txt | cut -d'|' -f2,3 | sort -u | cut -d',' -f2 | sed 's/^[[:space:]]*//' | head -5

# 6. 完整流程验证
cat enrollments.txt | ./final_q1.sh
```

## 强化练习题

### 题目：统计各课程人数 (Course Enrollment Count)

利用同样的 `enrollments.txt` 输入，请写一个Pipeline输出：
- 每门课程的课程代码（如COMP2041）
- 该课程有多少名学生选修
- 按人数从高到低排列；如果人数相同，按课程代码字母序排列

### 期望输出格式：
```
COMP3311 3
COMP3331 3
COMP2041 2
COMP1917 2
...
```

### 解题提示：
1. 先用 `cut` 提取课程和学号
2. 使用 `sort -u` 确保每人每课只算一次
3. 再 `cut` 出课程列
4. 使用 `sort | uniq -c` 统计每门课出现的次数
5. 使用 `sort -k1,1nr -k2,2` 进行多级排序

### 参考答案：
```bash
#!/bin/bash
# 统计课程人数

cut -d'|' -f1,2 | sort -u | cut -d'|' -f1 | sort | uniq -c | sort -k1,1nr -k2,2 | awk '{print $2, $1}'
```

### 分步解析：
1. `cut -d'|' -f1,2`：提取课程和学号
2. `sort -u`：基于"课程+学号"去重
3. `cut -d'|' -f1`：只保留课程列
4. `sort | uniq -c`：统计每门课出现次数
5. `sort -k1,1nr -k2,2`：按计数降序，课程代码升序
6. `awk '{print $2, $1}'`：调整输出格式（课程 人数）
