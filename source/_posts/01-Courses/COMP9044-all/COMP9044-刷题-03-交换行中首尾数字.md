# COMP9044 刷题03 - Python正则表达式实战：交换行中首尾数字

> 本文记录COMP9044课程中的Python题目：使用正则表达式处理文本，交换每行中首尾两个数字。通过这道题深入理解Python正则表达式的使用技巧和字符串操作。

## 题目描述

### 题目来源
COMP9044 202T2 Question 5

### 问题描述
编写一个Python程序，从标准输入读取文本行，如果一行包含两个或更多整数，则交换第一个和最后一个整数。

具体要求：
1. 如果一行包含少于两个整数，则原样打印
2. 如果一行包含多于两个整数，只交换第一个和最后一个
3. 程序文件名为 `./final_q5.py`

### 输入输出示例
```bash
$ cat swap_numbers.txt
And the first 24 shall become 42 
last 1 is the loneliest number
Some lines have no numbers
Powers of 10 are: 1 10 100 1000
The answer is 42.
6 * 7 = 42

$ ./final_q5.py < swap_numbers.txt
And the first 42 shall become 24
last 1 is the loneliest number
Some lines have no numbers
Powers of 1000 are: 1 10 100 10
The answer is 42.
42 * 7 = 6
```

## 解题思路

### 核心算法
1. **使用正则表达式查找所有数字**：`re.finditer(r'\d+', line)`
2. **统计数字数量**：如果少于2个，直接输出
3. **获取首尾数字信息**：位置、内容、起止索引
4. **字符串重组**：交换首尾数字位置

### 关键技巧
- `re.finditer()` 返回匹配对象的迭代器，包含位置信息
- 字符串切片操作实现精确替换
- 处理边界情况（空行、无数字、单个数字）

## 代码实现

### 完整解决方案
```python
#!/usr/bin/env python3
# final_q5.py - 交换行中首尾数字

import sys
import re

def process_line(line):
    """
    处理单行文本，交换首尾数字
    
    参数:
        line: 输入文本行
        
    返回:
        处理后的文本行
    """
    # 使用正则表达式查找所有数字及其位置
    matches = list(re.finditer(r'\d+', line))
    
    # 统计数字数量
    number_count = len(matches)
    
    # 如果少于2个数字，直接返回原行
    if number_count < 2:
        return line
    
    # 获取第一个和最后一个数字的信息
    first_match = matches[0]
    last_match = matches[-1]
    
    # 提取位置信息
    first_start = first_match.start()
    first_end = first_match.end()
    first_num = first_match.group()
    
    last_start = last_match.start()
    last_end = last_match.end()
    last_num = last_match.group()
    
    # 重组字符串：交换首尾数字
    # 格式：原字符串 + 替换逻辑
    new_line = (
        line[:first_start] +           # 第一个数字之前的部分
        last_num +                     # 用最后一个数字替换第一个数字
        line[first_end:last_start] +   # 两个数字之间的部分
        first_num +                    # 用第一个数字替换最后一个数字
        line[last_end:]                # 最后一个数字之后的部分
    )
    
    return new_line

def main():
    """主函数：处理标准输入"""
    for line in sys.stdin:
        # 处理每一行并输出
        result = process_line(line)
        print(result, end='')

if __name__ == "__main__":
    main()
```

### 优化版本（更健壮）
```python
#!/usr/bin/env python3
# final_q5_optimized.py - 优化版本

import sys
import re

def swap_first_last_numbers(line):
    """
    交换行中首尾数字的优化版本
    
    特点:
    1. 使用命名分组提高可读性
    2. 添加输入验证
    3. 更好的错误处理
    4. 支持多种数字格式
    """
    # 验证输入
    if not isinstance(line, str):
        return line
    
    # 查找所有数字（支持负数和小数）
    # \d+ 匹配一个或多个数字
    pattern = r'\d+'
    matches = list(re.finditer(pattern, line))
    
    # 检查数字数量
    if len(matches) < 2:
        return line
    
    # 获取匹配信息
    first = matches[0]
    last = matches[-1]
    
    # 确保位置不重叠（理论上不会，但安全检查）
    if first.end() > last.start():
        # 如果数字重叠或顺序错误，返回原行
        return line
    
    # 执行交换
    result = (
        line[:first.start()] +
        last.group() +
        line[first.end():last.start()] +
        first.group() +
        line[last.end():]
    )
    
    return result

def process_input():
    """处理标准输入流"""
    try:
        for line_num, line in enumerate(sys.stdin, 1):
            # 保留行尾换行符
            has_newline = line.endswith('\n')
            line_content = line.rstrip('\n')
            
            # 处理内容
            processed = swap_first_last_numbers(line_content)
            
            # 输出结果
            if has_newline:
                print(processed)
            else:
                print(processed, end='')
                
    except KeyboardInterrupt:
        # 处理Ctrl+C
        sys.exit(0)
    except Exception as e:
        print(f"Error processing input: {e}", file=sys.stderr)
        sys.exit(1)

if __name__ == "__main__":
    process_input()
```

## 详细分析

### 正则表达式详解

#### 1. 基本模式 `r'\d+'`
- `\d`：匹配任意数字（0-9），等价于 `[0-9]`
- `+`：匹配前一个字符1次或多次
- `r''`：原始字符串，避免转义字符问题

#### 2. `re.finditer()` vs `re.findall()`
```python
# re.findall() - 只返回匹配的字符串列表
numbers = re.findall(r'\d+', line)  
# 示例: ['24', '42'] - 丢失位置信息

# re.finditer() - 返回匹配对象的迭代器
matches = re.finditer(r'\d+', line)
# 每个match对象包含: group(), start(), end(), span()
```

#### 3. 匹配对象的方法
```python
match = next(re.finditer(r'\d+', "abc123def"))
print(match.group())   # '123' - 匹配的字符串
print(match.start())   # 3 - 起始索引
print(match.end())     # 6 - 结束索引（不包含）
print(match.span())    # (3, 6) - (start, end)元组
```

### 字符串重组逻辑

#### 原始字符串结构：
```
line = "And the first 24 shall become 42"
索引:   0          ^18   ^20          ^31 ^33
        |          |     |            |   |
        |         第一个数字          |   最后一个数字
        |         (24: 18-20)        |   (42: 31-33)
        |                            |
        |                           两个数字之间的部分
        |                           (20-31)
```

#### 重组过程：
```python
new_line = (
    line[:18] +        # "And the first "
    "42" +             # 最后一个数字
    line[20:31] +      # " shall become "
    "24" +             # 第一个数字
    line[33:]          # "" (空字符串)
)
# 结果: "And the first 42 shall become 24"
```

### 边界情况处理

#### 1. 无数字行
```python
line = "Some lines have no numbers"
matches = list(re.finditer(r'\d+', line))  # []
len(matches) < 2 → 直接返回原行
```

#### 2. 单个数字行
```python
line = "last 1 is the loneliest number"
matches = [<match object for '1'>]
len(matches) == 1 < 2 → 直接返回原行
```

#### 3. 多个数字行
```python
line = "Powers of 10 are: 1 10 100 1000"
matches = ['10', '1', '10', '100', '1000']
交换: '10' ↔ '1000'
结果: "Powers of 1000 are: 1 10 100 10"
```

#### 4. 数字相邻的情况
```python
line = "123 456"
# 第一个数字: 123 (0-3)
# 最后一个数字: 456 (4-7)
# 交换后: "456 123"
```

## Python正则表达式基础知识

### 常用元字符

| 元字符 | 描述 | 示例 | 匹配 |
|--------|------|------|------|
| `.` | 匹配任意字符（除换行符） | `a.c` | abc, a c, a-c |
| `^` | 匹配字符串开头 | `^Hello` | Hello world |
| `$` | 匹配字符串结尾 | `world$` | Hello world |
| `*` | 前一个字符0次或多次 | `ab*c` | ac, abc, abbc |
| `+` | 前一个字符1次或多次 | `ab+c` | abc, abbc |
| `?` | 前一个字符0次或1次 | `ab?c` | ac, abc |
| `{m}` | 前一个字符m次 | `a{3}` | aaa |
| `{m,n}` | 前一个字符m到n次 | `a{2,4}` | aa, aaa, aaaa |
| `[]` | 字符集 | `[aeiou]` | 任意元音字母 |
| `|` | 或 | `cat|dog` | cat 或 dog |
| `()` | 分组 | `(ab)+` | ab, abab |

### 特殊字符类

| 字符类 | 等价表示 | 描述 |
|--------|----------|------|
| `\d` | `[0-9]` | 数字 |
| `\D` | `[^0-9]` | 非数字 |
| `\w` | `[a-zA-Z0-9_]` | 单词字符 |
| `\W` | `[^a-zA-Z0-9_]` | 非单词字符 |
| `\s` | `[ \t\n\r\f\v]` | 空白字符 |
| `\S` | `[^ \t\n\r\f\v]` | 非空白字符 |

### re模块常用函数

#### 1. `re.search()` - 搜索第一个匹配
```python
import re
text = "The price is $100"
match = re.search(r'\$\d+', text)
if match:
    print(match.group())  # $100
```

#### 2. `re.match()` - 从开头匹配
```python
# 只匹配字符串开头
match = re.match(r'\d+', "123 abc")  # 匹配
match = re.match(r'\d+', "abc 123")  # 不匹配
```

#### 3. `re.findall()` - 查找所有匹配
```python
text = "a1 b2 c3 d4"
numbers = re.findall(r'\d', text)  # ['1', '2', '3', '4']
```

#### 4. `re.finditer()` - 查找所有匹配（返回迭代器）
```python
text = "a1 b2 c3"
for match in re.finditer(r'\d', text):
    print(f"Found {match.group()} at {match.start()}")
```

#### 5. `re.sub()` - 替换匹配
```python
text = "Hello 123 World 456"
result = re.sub(r'\d+', 'NUM', text)  # "Hello NUM World NUM"
```

#### 6. `re.split()` - 根据模式分割
```python
text = "apple,banana;cherry orange"
parts = re.split(r'[,; ]', text)  # ['apple', 'banana', 'cherry', 'orange']
```

### 编译正则表达式（提高性能）
```python
# 对于需要多次使用的模式，先编译
pattern = re.compile(r'\d+')

# 然后使用编译后的模式
matches = pattern.finditer(text)
result = pattern.sub('NUM', text)
```

## 常见错误与调试技巧

### 错误1：忘记使用原始字符串
```python
# ❌ 错误：\d 被转义
pattern = '\d+'  # 实际是: '\\d+'

# ✅ 正确：使用原始字符串
pattern = r'\d+'
```

### 错误2：错误理解匹配位置
```python
# match.end() 返回的是结束索引（不包含）
text = "abc123def"
match = re.search(r'\d+', text)
print(text[match.start():match.end()])  # '123'
print(text[match.start():match.end()-1])  # '12' ❌
```

### 错误3：未处理重叠匹配
```python
# 如果模式可能产生重叠匹配
text = "aaa"

```python
def process_line_generator(line):
    # 直接使用迭代器，不转换为列表
    matches_iter = re.finditer(r'\d+', line)
    
    # 获取第一个匹配
    try:
        first_match = next(matches_iter)
    except StopIteration:
        return line  # 无匹配
    
    # 获取最后一个匹配
    last_match = first_match
    for match in matches_iter:
        last_match = match
    
    # 如果
