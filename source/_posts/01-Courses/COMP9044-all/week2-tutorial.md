# 第二阶段： 核心工具笔记

## 1. sort  -排序

---

```sort``` : 不仅仅是排序， 关键在于 ```-k(key)``` 定位字段和 ```-n(numeric)``` 按排序排

| 选项 | 含义 | 示例 |
|------|------|------|
| -k F,F(F表示 Field， 字段) | 按第 F 个字段排序 | sort -k2,2 |
| -t 'SEP' | 按照指定分隔符排序 | sort -t '|' |
| -n | 数值排序(非字典序) | sort -k3,3n |
|-r | 逆序排序 | sort -k2,2r |
| -k F.c | 从第F个字段的第c个字符开始 |-k1.8,1n |

### 多键排序

```sort -k3,3 -k2,2 benchmarks```

⚠️ -k2,2 和 -k2 的区别：-k2 表示"从第2字段到行尾"，-k2,2 才表示"仅第2字段"。做精确排序时要加结束列号!

---

**练习1-A**
下面的文件是 benchmarks（Tab 分隔），第2列是"第一基准"，第3列是"第二基准"，第4列是"第三基准"。
写命令：先按第三基准排序，再按程序编号（字段1中数字部分）排序。

|   基准1   |   基准2   |   基准3   |   基准4   |
|   program1    |   08  |   03  |   05  |
|   program10   |   09    |   04  |   16  |
|   program2    |   14    |   03  |   05  |

**参考答案**

```shell

sort -k4,4 -k1.8,1n benchmarks.txt

```

-k1.8,1n 表示从第1个字段的第8个字符("Program"后面的数字开始)， 按照数值排序。 这样Program2就排在Program10的前面了

---

**练习1-B**
有一个管道符分隔的成绩文件 marks.psv（格式：zID|mark），如何按 zID 排序并保存到 marks-sorted.psv？


**参考答案**
```shell
sort -t '|' -k1,1 marks.psv > marks-sorted.psv
```

## 2. cut -提取字段/字符

```cut``` : 垂直切割。 用 ```-d``` 指定分隔符， 

| 选项 | 含义 | 
|------|------|
|-d'SEP' | 指定字段分隔符（默认Tab） |
| -f N(N表示Number 数字/索引)	| 提取第 N 个字段（从1开始）|
|-f 1,3	| 提取第1和第3字段  |
| -c N	| 提取第 N 个字符   |

**例如: 从 /etc/passwd/ 提取用户名：(第1字段， 冒号分隔)**

```shell
cut -d':' -f1 /etc/passwd
```

**再比如：提取用户名和密码，然后换成Tab分隔符**
```shell
cut -d':' -f1,2 /etc/passwd | tr ':' '\t' > passwords.txt
```
---

**练习2-A**

给定 /etc/passwd，请写命令只输出所有用户的家目录（第6字段）。

**参考答案**

```shell
cut -d':' -f6,6 /etc/passwd
```
