## COMP9044 Shell编程与Python实践

### 课程特点
COMP9044是一门综合性的系统编程课程，结合Shell脚本编程和Python实践，通过两种语言的对比学习，深入理解数据处理和系统编程的核心概念。

### 学习目标
1. 掌握Shell脚本编程基础和Python数据处理
2. 熟练使用Linux命令行工具和Python标准库
3. 理解管道和重定向机制，以及对应的Python实现
4. 能够编写复杂的Shell脚本和Python程序
5. 建立跨语言编程思维，灵活选择合适工具

### 题目分类
1. **Shell基础**：文件操作、文本处理、命令组合
2. **Python实践**：标准输入处理、字符串解析、数据结构
3. **脚本编程**：变量、条件、循环、函数（两种语言）
4. **高级应用**：进程管理、信号处理、正则表达式
5. **实战项目**：自动化脚本、系统管理工具、数据处理管道

### 学习资源
- [Bash Reference Manual](https://www.gnu.org/software/bash/manual/)
- [Linux Command Library](https://linuxcommandlibrary.com/)
- [ShellCheck](https://www.shellcheck.net/) - Shell脚本检查工具

## COMP9417 机器学习

### 学习目标
1. 理解机器学习基本概念和算法
2. 掌握Python机器学习库的使用
3. 能够完成实际的机器学习项目
4. 理解模型评估和优化方法

### 学习内容
1. **基础理论**：监督学习、无监督学习、强化学习
2. **经典算法**：线性回归、逻辑回归、决策树、SVM、神经网络
3. **实践技能**：数据预处理、特征工程、模型训练、超参数调优
4. **高级主题**：深度学习、自然语言处理、计算机视觉

### 学习资源
- [Coursera Machine Learning](https://www.coursera.org/learn/machine-learning)
- [Scikit-learn Documentation](https://scikit-learn.org/stable/documentation.html)
- [TensorFlow Tutorials](https://www.tensorflow.org/tutorials)

## 博客写作规范

### 文章结构
1. **问题描述**：清晰说明题目要求
2. **解题思路**：分析问题，设计解决方案
3. **代码实现**：提供完整可运行的代码
4. **测试验证**：展示测试用例和结果
5. **分析总结**：总结关键点和学习收获
6. **扩展思考**：提出相关问题和进阶方向

### 代码要求
- 代码完整，可独立运行
- 添加必要的注释
- 考虑边界情况和错误处理
- 讨论时间复杂度和空间复杂度

### 写作质量
- 技术准确，逻辑清晰
- 语言简洁，表达准确
- 实例丰富，易于理解
- 总结提炼，价值明确
