# 0086. 分隔链表 - 双虚拟头结点技巧与断链陷阱详解

> 本文深入分析LeetCode第86题"分隔链表"，重点讲解双虚拟头结点技巧和"断链陷阱"的避免方法，这是链表操作中容易出错的关键点。

## 题目描述

### 英文题目
Partition List

### 中文题目
给你一个链表的头节点 `head` 和一个特定值 `x` ，请你对链表进行分隔，使得所有 **小于** `x` 的节点都出现在 **大于或等于** `x` 的节点之前。

你应当 **保留** 两个分区中每个节点的初始相对位置。

### 示例
```
输入：head = [1,4,3,2,5,2], x = 3
输出：[1,2,2,4,3,5]
解释：
小于3的节点：1,2,2
大于等于3的节点：4,3,5
保持相对位置：1,2,2,4,3,5

输入：head = [2,1], x = 2
输出：[1,2]
解释：
小于2的节点：1
大于等于2的节点：2
保持相对位置：1,2
```

### 约束条件
- 链表中节点的数目在范围 `[0, 200]` 内
- `-100 <= Node.val <= 100`
- `-200 <= x <= 200`

## 解题思路

### 核心思想
使用**两个虚拟头结点**分别构建小于x的链表和大于等于x的链表，最后将两个链表连接起来。

### 关键技巧
1. **双虚拟头结点**：简化边界处理
2. **断链操作**：移动节点时必须断开原连接
3. **保持相对位置**：按原顺序遍历，自然保持相对位置

### 算法步骤
1. 创建两个虚拟头结点：`dummy1`（小于x），`dummy2`（大于等于x）
2. 创建两个指针：`p1`指向`dummy1`，`p2`指向`dummy2`
3. 遍历原链表：
   - 如果`curr.val < x`：连接到`p1`链表
   - 否则：连接到`p2`链表
4. 连接两个链表：`p1.next = dummy2.next`
5. 断开尾节点：`p2.next = None`
6. 返回`dummy1.next`

## 代码实现

### 标准解法
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def partition(self, head: Optional[ListNode], x: int) -> Optional[ListNode]:
        """
        分隔链表 - 双虚拟头结点方法
        
        时间复杂度: O(n)，一次遍历
        空间复杂度: O(1)，只使用常数额外空间
        
        关键点:
        1. 使用两个虚拟头结点简化操作
        2. 移动节点时必须断开原连接
        3. 最后要断开第二个链表的尾节点
        """
        # 创建两个虚拟头结点
        dummy1 = ListNode(-1)  # 存储小于x的节点
        dummy2 = ListNode(-1)  # 存储大于等于x的节点
        
        p1 = dummy1  # 小于x链表的当前指针
        p2 = dummy2  # 大于等于x链表的当前指针
        
        curr = head  # 原链表遍历指针
        
        while curr:
            if curr.val < x:
                # 连接到小于x的链表
                p1.next = curr
                p1 = p1.next
            else:
                # 连接到大于等于x的链表
                p2.next = curr
                p2 = p2.next
            
            # ⚠️ 关键：必须断开原连接，否则可能形成环
            # 先保存下一个节点，再断开当前节点的连接
            temp = curr.next
            curr.next = None
            curr = temp
        
        # 连接两个链表
        p1.next = dummy2.next
        
        # 断开第二个链表的尾节点（可能已经有None，但安全起见）
        p2.next = None
        
        return dummy1.next
```

### 优化版本（更清晰的断链）
```python
class Solution:
    def partition(self, head: Optional[ListNode], x: int) -> Optional[ListNode]:
        # 创建两个虚拟头结点
        less_head = ListNode(-1)
        greater_head = ListNode(-1)
        
        less = less_head
        greater = greater_head
        
        while head:
            # 保存下一个节点
            next_node = head.next
            
            if head.val < x:
                # 连接到小于x的链表
                less.next = head
                less = less.next
                # 立即断开连接
                less.next = None
            else:
                # 连接到大于等于x的链表
                greater.next = head
                greater = greater.next
                # 立即断开连接
                greater.next = None
            
            # 移动到下一个节点
            head = next_node
        
        # 连接两个链表
        less.next = greater_head.next
        
        return less_head.next
```

### 错误示范（常见陷阱）
```python
class Solution:
    def partition_wrong(self, head: Optional[ListNode], x: int) -> Optional[ListNode]:
        # ❌ 错误：没有断开原连接
        dummy1 = ListNode(-1)
        dummy2 = ListNode(-1)
        
        p1 = dummy1
        p2 = dummy2
        
        curr = head
        
        while curr:
            if curr.val < x:
                p1.next = curr
                p1 = p1.next
            else:
                p2.next = curr
                p2 = p2.next
            
            # ❌ 错误：直接移动，没有断开连接
            curr = curr.next  # 这里curr.next可能指向原链表的下一个节点
        
        # 连接两个链表
        p1.next = dummy2.next
        
        # ❌ 可能形成环或错误连接
        return dummy1.next
```

## 详细分析

### 双虚拟头结点的作用

#### 初始状态
```
原链表: 1 → 4 → 3 → 2 → 5 → 2 → None, x=3

dummy1 → X (小于3)
dummy2 → X (大于等于3)

p1 = dummy1
p2 = dummy2
curr = 1
```

#### 遍历过程
```
第1步: curr.val=1 < 3
p1.next = 1
p1 = 1
断开: 1.next = None
curr = 4

第2步: curr.val=4 >= 3
p2.next = 4
p2 = 4
断开: 4.next = None
curr = 3

第3步: curr.val=3 >= 3
p2.next = 3
p2 = 3
断开: 3.next = None
curr = 2

... 以此类推
```

#### 最终连接
```
遍历完成后:
dummy1 → 1 → 2 → 2 → None
dummy2 → 4 → 3 → 5 → None

连接: 2.next = 4
结果: 1 → 2 → 2 → 4 → 3 → 5 → None
```

### 断链陷阱详解

#### 为什么需要断开连接？
```
原链表: A → B → C → D → None, x=2

假设A.val=1 < 2, B.val=3 >= 2

错误操作:
p1.next = A  # A连接到小于链表
p1 = A
# 没有断开A.next，A仍然指向B

p2.next = B  # B连接到大于等于链表
p2 = B
# 没有断开B.next，B仍然指向C

最终连接后:
小于链表: A → B → C → D → None
大于等于链表: B → C → D → None

连接: A.next = B
结果: A → B → C → D → None ❌ 错误！
实际上形成了: A → B → C → D → B → C → D → ... 环！
```

#### 正确断链操作
```python
# 关键四步
temp = curr.next    # 1. 保存下一个节点
curr.next = None    # 2. 断开当前节点的连接
p1.next = curr      # 3. 连接到新链表
curr = temp         # 4. 移动到下一个节点
```

### 保持相对位置
由于是按原顺序遍历，自然保持了相对位置：
- 小于x的节点按原顺序连接
- 大于等于x的节点按原顺序连接
- 最后连接两个链表，保持整体相对位置

## 性能分析

### 时间复杂度
- **遍历链表**：O(n)，每个节点访问一次
- **连接操作**：O(1)
- **总计**：O(n)

### 空间复杂度
- **虚拟头结点**：O(1)，常数空间
- **指针变量**：O(1)
- **总计**：O(1)

### 与数组方法的对比
| 方法 | 时间复杂度 | 空间复杂度 | 是否保持相对位置 | 是否稳定 |
|------|------------|------------|------------------|----------|
| 链表双虚拟头结点 | O(n) | O(1) | 是 | 是 |
| 数组收集再连接 | O(n) | O(n) | 是 | 是 |
| 快速排序思路 | O(n) | O(1) | 否 | 否 |

## 常见错误

### 错误1：忘记断链（形成环）
```python
# ❌ 错误代码
while curr:
    if curr.val < x:
        p1.next = curr
        p1 = p1.next
    else:
        p2.next = curr
        p2 = p2.next
    curr = curr.next  # 没有断开curr.next！
```

### 错误2：断链顺序错误
```python
# ❌ 错误：先移动再断链
curr = curr.next      # 先移动
curr.next = None      # 断错了节点！

# ✅ 正确：先断链再移动
temp = curr.next      # 保存
curr.next = None      # 断开
curr = temp           # 移动
```

### 错误3：忘记断开第二个链表的尾节点
```python
# ❌ 错误：可能形成环
p1.next = dummy2.next
# 忘记: p2.next = None

# ✅ 正确
p1.next = dummy2.next
p2.next = None  # 确保尾节点为None
```
