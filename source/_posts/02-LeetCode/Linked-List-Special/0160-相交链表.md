# 0160. 相交链表 - 双指针消除长度差技巧详解

> 本文深入分析LeetCode第160题"相交链表"，重点讲解如何通过双指针技巧消除链表长度差异，在不计算长度的情况下找到交点。

## 题目描述

### 英文题目
Intersection of Two Linked Lists

### 中文题目
给你两个单链表的头节点 `headA` 和 `headB` ，请你找出并返回两个单链表相交的起始节点。如果两个链表没有交点，返回 `null` 。

图示两个链表在节点 `c1` 开始相交：

```
A:          a1 → a2
                    ↘
                      c1 → c2 → c3
                    ↗            
B:    b1 → b2 → b3
```

题目数据 **保证** 整个链式结构中不存在环。

注意，函数返回结果后，链表必须 **保持其原始结构** 。

### 示例
```
输入：intersectVal = 8, listA = [4,1,8,4,5], listB = [5,6,1,8,4,5], skipA = 2, skipB = 3
输出：Intersected at '8'
解释：相交节点的值为 8（注意，如果两个链表相交则不能为 0）。
从各自的表头开始算起，链表 A 为 [4,1,8,4,5]，链表 B 为 [5,6,1,8,4,5]。
在 A 中，相交节点前有 2 个节点；在 B 中，相交节点前有 3 个节点。

输入：intersectVal = 2, listA = [1,9,1,2,4], listB = [3,2,4], skipA = 3, skipB = 1
输出：Intersected at '2'

输入：intersectVal = 0, listA = [2,6,4], listB = [1,5], skipA = 3, skipB = 2
输出：null
解释：从各自的表头开始算起，链表 A 为 [2,6,4]，链表 B 为 [1,5]。
由于这两个链表不相交，所以 intersectVal 必须为 0，而 skipA 和 skipB 可以是任意值。
这两个链表不相交，因此返回 null。
```

### 进阶
你能否设计一个时间复杂度 O(n) 、仅用 O(1) 内存的解决方案？

### 约束条件
- `listA` 中节点数目为 `m`
- `listB` 中节点数目为 `n`
- `0 <= m, n <= 3 * 10^4`
- `1 <= Node.val <= 10^5`
- `0 <= skipA <= m`
- `0 <= skipB <= n`
- 如果 `listA` 和 `listB` 没有交点，`intersectVal` 为 `0`
- 如果 `listA` 和 `listB` 有交点，`intersectVal == listA[skipA] == listB[skipB]`

## 解题思路

### 核心思想
使用**双指针技巧**消除两个链表的长度差异：
- 指针 `pA` 从链表A开始，走完A后转到B
- 指针 `pB` 从链表B开始，走完B后转到A
- 如果两个链表相交，指针会在交点相遇
- 如果两个链表不相交，指针会同时到达末尾（None）

### 算法原理
设：
- 链表A独有部分长度为 `a`
- 链表B独有部分长度为 `b`
- 公共部分长度为 `c`

指针 `pA` 的路径：`a + c + b`
指针 `pB` 的路径：`b + c + a`

两个指针走过的总长度相同，如果相交会在交点相遇，如果不相交会同时到达None。

## 代码实现

### 标准解法（双指针）
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        """
        找到两个链表的交点 - 双指针消除长度差
        
        时间复杂度: O(m + n)
        空间复杂度: O(1)
        
        算法原理:
        1. 指针pA从A开始，走完A后转到B
        2. 指针pB从B开始，走完B后转到A
        3. 如果相交，会在交点相遇；如果不相交，会同时到达None
        """
        if not headA or not headB:
            return None
        
        pA, pB = headA, headB
        
        # 关键：当pA和pB不相同时继续循环
        # 两种情况结束循环：
        # 1. pA == pB != None (找到交点)
        # 2. pA == pB == None (没有交点)
        while pA != pB:
            # pA走到末尾后转到headB
            pA = pA.next if pA else headB
            # pB走到末尾后转到headA
            pB = pB.next if pB else headA
        
        # pA可能是交点或None
        return pA
```

### 哈希表方法（对比）
```python
class Solution:
    def getIntersectionNode_hash(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        """
        哈希表方法 - 记录访问过的节点
        
        时间复杂度: O(m + n)
        空间复杂度: O(m) 或 O(n)
        
        优点: 逻辑简单直观
        缺点: 需要额外空间
        """
        visited = set()
        curr = headA
        
        # 遍历链表A，记录所有节点
        while curr:
            visited.add(curr)
            curr = curr.next
        
        # 遍历链表B，检查是否已访问
        curr = headB
        while curr:
            if curr in visited:
                return curr
            curr = curr.next
        
        return None
```

### 计算长度方法（对比）
```python
class Solution:
    def getIntersectionNode_length(self, headA: ListNode, headB: ListNode) -> Optional[ListNode]:
        """
        计算长度方法
        1. 分别计算两个链表的长度
        2. 让长链表的指针先走长度差步
        3. 然后两个指针同步前进，比较节点
        
        时间复杂度: O(m + n)
        空间复杂度: O(1)
        """
        def get_length(head):
            length = 0
            while head:
                length += 1
                head = head.next
            return length
        
        lenA = get_length(headA)
        lenB = get_length(headB)
        
        pA, pB = headA, headB
        
        # 让长链表的指针先走长度差步
        if lenA > lenB:
            for _ in range(lenA - lenB):
                pA = pA.next
        else:
            for _ in range(lenB - lenA):
                pB = pB.next
        
        # 同步前进，比较节点
        while pA and pB:
            if pA == pB:
                return pA
            pA = pA.next
            pB = pB.next
        
        return None
```

## 详细分析

### 双指针算法原理证明

#### 情况1：两个链表相交
```
链表A: A1 → A2 → C1 → C2 → C3 → None
链表B: B1 → B2 → B3 → C1 → C2 → C3 → None
交点: C1

设:
a = 2 (A1,A2)
b = 3 (B1,B2,B3)
c = 3 (C1,C2,C3)

指针路径:
pA: A1→A2→C1→C2→C3→B1→B2→B3→C1 (总长: a+c+b)
pB: B1→B2→B3→C1→C2→C3→A1→A2→C1 (总长: b+c+a)

在C1相遇！
```

#### 情况2：两个链表不相交
```
链表A: A1 → A2 → A3 → None
链表B: B1 → B2 → None

指针路径:
pA: A1→A2→A3→B1→B2→None (总长: 3+2=5)
pB: B1→B2→A1→A2→A3→None (总长: 2+3=5)

在None处"相遇"！
```

#### 数学公式
设链表A长度为 `m`，链表B长度为 `n`，公共部分长度为 `c`（如果不相交则 `c=0`）：
- `pA` 总路径：`(m - c) + c + (n - c) = m + n - c`
- `pB` 总路径：`(n - c) + c + (m - c) = m + n - c`

两个指针走过相同长度后：
- 如果 `c > 0`：在交点相遇
- 如果 `c = 0`：在None处"相遇"

#### 2. 一个链表是另一个的前缀

# 交点: 1
# 算法正常工作
```

### 循环终止条件

#### 为什么是 `while pA != pB`？
```python
# 关键：循环直到pA和pB相等
# 两种情况会相等：
# 1. 指向同一个节点（交点）
# 2. 都指向None（没有交点）

while pA != pB:
    pA = pA.next if pA else headB
    pB = pB.next if pB else headA

# 循环结束时，pA == pB
# 可能是交点节点，也可能是None
return pA
```

#### 不会无限循环的证明
每个指针最多走 `m + n` 步：
- 走完自己的链表：`m` 或 `n` 步
- 走完另一个链表：`n` 或 `m` 步
- 总计：`m + n` 步

由于每次循环都移动指针，最多 `m + n` 次循环后一定会结束。

## 性能分析

### 时间复杂度对比

| 方法 | 时间复杂度 | 扫描次数 | 优点 | 缺点 |
|------|------------|----------|------|------|
| 双指针 | O(m + n) | 1趟（每个指针） | 空间最优，巧妙 | 需要理解原理 |
| 哈希表 | O(m + n) | 2趟 | 逻辑简单 | 空间O(min(m,n)) |
| 计算长度 | O(m + n) | 3趟 | 容易理解 | 需要计算长度 |

### 空间复杂度对比

| 方法 | 空间复杂度 | 说明 |
|------|------------|------|
| 双指针 | O(1) | 只使用常数额外空间 |
| 哈希表 | O(min(m,n)) | 需要存储一个链表的节点 |
| 计算长度 | O(1) | 只使用常数额外空间 |

### 实际性能考虑
- **链表长度差异大**：双指针方法最优
- **需要简单实现**：哈希表方法最直观
- **内存限制严格**：必须使用双指针或计算长度方法
- **频繁调用**：计算长度方法可能稍快（减少条件判断）

## 常见错误

### 错误1：指针移动逻辑错误
```python
# ❌ 错误：没有正确处理末尾转换
while pA != pB:
    pA = pA.next  # 如果pA为None，这里报错
    pB = pB.next  # 如果pB为None，这里报错

# ✅ 正确：使用三元表达式
while pA != pB:
    pA = pA.next if pA else headB
    pB = pB.next if pB else headA
```

### 错误2：循环条件错误
```python
# ❌ 错误：使用and而不是!=
while pA and pB:  # 如果链表长度不同，可能提前结束
    if pA == pB:
        return pA
    pA = pA.next if pA else headB
    pB = pB.next if pB else headA

# ✅ 正确：使用!=
while pA != pB:
    pA = pA.next if pA else headB
    pB = pB.next if pB else headA
```

### 错误3：忘记处理空链表
```python
# ❌ 错误：直接开始循环
pA, pB = headA, headB
while pA != pB:
    # 如果headA或headB为None，pA.next或pB.next可能报错

# ✅ 正确：先检查空链表
if not headA or not headB:
    return None
```

### 错误4：修改了原链表
```python
# ❌ 错误：修改了链表结构
def getIntersectionNode_wrong(headA, headB):
    # 连接两个链表，但修改了原结构
    curr = headA
    while curr.next:
        curr = curr.next
    curr.next = headB  # 修改了链表A！
    # ... 其他逻辑
    
# 题目要求：不能修改链表结构
```

## 算法变体

### 变体1：记录访问次数
```python
def getIntersectionNode_count(self, headA, headB):
    """
    记录访问次数的版本
    每个节点最多被访问2次
    """
    pA, pB = headA, headB
    countA = countB = 0
    
    # 每个指针最多访问两个链表各一次
    while countA < 2 and countB < 2:
        if pA == pB:
            return pA
        
        pA = pA.next
        if not p
