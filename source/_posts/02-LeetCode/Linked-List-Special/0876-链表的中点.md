# 0876. 链表的中点 - 快慢指针技巧与边界条件详解

> 本文深入分析LeetCode第876题"链表的中点"，这是快慢指针技巧最基础的应用，也是理解双指针算法的入门题目。

## 题目描述

### 英文题目
Middle of the Linked List

### 中文题目
给定一个头结点为 `head` 的非空单链表，返回链表的中间结点。

如果有两个中间结点，则返回第二个中间结点。

### 示例
```
输入：[1,2,3,4,5]
输出：节点3
解释：链表只有一个中间结点，值为3。

输入：[1,2,3,4,5,6]
输出：节点4
解释：该链表有两个中间结点，值分别为3和4，返回第二个结点。
```

### 进阶
你可以用时间复杂度 O(n) 和空间复杂度 O(1) 解决此问题吗？

### 约束条件
- 给定链表的结点数介于 `1` 和 `100` 之间

## 解题思路

### 核心思想
使用**快慢指针**技巧：
- 慢指针 `slow` 每次走1步
- 快指针 `fast` 每次走2步
- 当快指针到达链表末尾时，慢指针正好在中间位置

### 关键点
1. **快指针步进条件**：`fast and fast.next` 双重检查
2. **中间节点定义**：奇数长度取唯一中点，偶数长度取第二个中点
3. **边界条件**：链表非空（题目保证）

### 算法步骤
1. 初始化 `slow = fast = head`
2. 循环条件：`while fast and fast.next:`
3. 慢指针走1步：`slow = slow.next`
4. 快指针走2步：`fast = fast.next.next`
5. 返回 `slow`

## 代码实现

### 标准解法
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def middleNode(self, head: Optional[ListNode]) -> Optional[ListNode]:
        """
        找到链表的中点 - 快慢指针方法
        
        时间复杂度: O(n)，其中n是链表长度
        空间复杂度: O(1)，只使用常数额外空间
        
        关键点:
        1. 快指针每次走2步，慢指针每次走1步
        2. 循环条件: fast and fast.next
        3. 偶数长度时返回第二个中点
        """
        slow = fast = head
        
        # 关键：双重检查，确保fast和fast.next都不为None
        while fast and fast.next:
            slow = slow.next          # 慢指针走1步
            fast = fast.next.next     # 快指针走2步
        
        return slow
```

### 数组方法（对比）
```python
class Solution:
    def middleNode_array(self, head: Optional[ListNode]) -> Optional[ListNode]:
        """
        数组方法 - 将链表节点存入数组，直接访问中间位置
        
        时间复杂度: O(n)
        空间复杂度: O(n)，需要数组存储所有节点
        
        优点: 逻辑简单
        缺点: 需要额外空间
        """
        nodes = []
        curr = head
        
        while curr:
            nodes.append(curr)
            curr = curr.next
        
        # 中间位置：len(nodes) // 2
        # Python整数除法向下取整，正好符合"返回第二个中点"的要求
        return nodes[len(nodes) // 2]
```

### 两趟扫描方法（对比）
```python
class Solution:
    def middleNode_two_pass(self, head: Optional[ListNode]) -> Optional[ListNode]:
        """
        两趟扫描方法
        1. 第一趟计算链表长度
        2. 第二趟找到中间节点
        
        时间复杂度: O(2n) = O(n)
        空间复杂度: O(1)
        """
        # 第一趟：计算长度
        length = 0
        curr = head
        while curr:
            length += 1
            curr = curr.next
        
        # 第二趟：找到中间节点
        curr = head
        for _ in range(length // 2):
            curr = curr.next
        
        return curr
```

## 详细分析

### 快慢指针工作原理

#### 奇数长度链表
```
链表: 1 → 2 → 3 → 4 → 5 → None

初始化: slow=1, fast=1

第1轮: fast and fast.next = True
slow = 2, fast = 3

第2轮: fast and fast.next = True
slow = 3, fast = 5

第3轮: fast.next = None, 循环结束
结果: slow = 3 (中点)
```

#### 偶数长度链表
```
链表: 1 → 2 → 3 → 4 → 5 → 6 → None

初始化: slow=1, fast=1

第1轮: fast and fast.next = True
slow = 2, fast = 3

第2轮: fast and fast.next = True
slow = 3, fast = 5

第3轮: fast and fast.next = True
slow = 4, fast = None (fast.next.next = 6.next = None)

循环结束
结果: slow = 4 (第二个中点)
```

### 循环条件分析

#### 为什么需要 `fast and fast.next`？
```python
# 错误：只检查fast.next
while fast.next:          # 如果fast为None，访问.next报错
    slow = slow.next
    fast = fast.next.next

# 错误：只检查fast
while fast:               # fast可能为None，但fast.next.next可能报错
    slow = slow.next
    fast = fast.next.next  # 如果fast.next为None，这里报错

# 正确：双重检查
while fast and fast.next:  # 确保fast和fast.next都不为None
    slow = slow.next
    fast = fast.next.next  # 安全，因为fast.next存在
```

#### 步进安全性
```
fast指针需要走2步：fast.next.next
因此需要确保：
1. fast不为None（否则fast.next报错）
2. fast.next不为None（否则fast.next.next报错）

while fast and fast.next: 同时满足这两个条件
```

### 中点定义分析

#### 链表长度与中点位置
| 链表长度 | 中点位置(0-based) | 返回的节点 |
|----------|-------------------|------------|
| 1 | 0 | 第1个节点 |
| 2 | 1 | 第2个节点（第二个中点） |
| 3 | 1 | 第2个节点 |
| 4 | 2 | 第3个节点（第二个中点） |
| 5 | 2 | 第3个节点 |
| 6 | 3 | 第4个节点（第二个中点） |

#### 数学推导
对于长度为n的链表：
- 如果n为奇数：中点位置 = n // 2
- 如果n为偶数：返回第二个中点，位置 = n // 2

正好对应Python的整数除法 `n // 2`

## 边界条件处理

### 1. 单节点链表
```python
# head = [1]
slow = fast = head
while fast and fast.next:  # fast.next为None，循环不执行
    # 不执行
return slow  # 返回head，即节点1
```

### 2. 双节点链表
```python
# head = [1, 2]
slow = fast = head
第1轮: fast and fast.next = True
slow = 2, fast = None (fast.next.next = 2.next = None)
循环结束
return slow  # 返回节点2（第二个中点）
```

## 性能分析

### 时间复杂度对比

| 方法 | 时间复杂度 | 扫描次数 | 优点 | 缺点 |
|------|------------|----------|------|------|
| 快慢指针 | O(n) | 1趟 | 最优，一趟扫描 | 需要理解指针步进 |
| 数组方法 | O(n) | 1趟 | 逻辑简单 | 空间复杂度O(n) |
| 两趟扫描 | O(2n) = O(n) | 2趟 | 容易理解 | 需要两次遍历 |

### 空间复杂度对比

| 方法 | 空间复杂度 | 说明 |
|------|------------|------|
| 快慢指针 | O(1) | 只使用常数额外空间 |
| 数组方法 | O(n) | 需要数组存储所有节点 |
| 两趟扫描 | O(1) | 只使用常数额外空间 |

### 实际性能考虑
- **链表长度小(n<100)**：所有方法性能差异不大
- **链表长度大**：快慢指针方法最优（一趟扫描）
- **内存限制严格**：避免数组方法

## 常见错误

### 错误1：循环条件不完整
```python
# ❌ 错误：可能访问None的next属性
while fast.next:
    slow = slow.next
    fast = fast.next.next  # 如果fast.next为None，这里报错

# ✅ 正确：双重检查
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
```

### 错误2：指针移动顺序错误
```python
# ❌ 错误：先移动fast再移动slow，可能导致slow多走一步
fast = fast.next.next
slow = slow.next

# ✅ 正确：先移动slow再移动fast
slow = slow.next
fast = fast.next.next
```

### 错误3：忘记初始化
```python
# ❌ 错误：fast没有初始化
slow = head
while fast and fast.next:  # fast未定义
    # ...

# ✅ 正确：同时初始化
slow = fast = head
```

### 错误4：处理空链表
```python
# ❌ 错误：假设链表非空
slow = fast = head  # 如果head为None，没问题
while fast and fast.next:  # fast为None，循环不执行
    # ...
return slow  # 返回None，正确但应该显式检查

# ✅ 更好：显式检查
if not head:
    return None
```

## 变体问题

### 变体1：返回第一个中点（偶数长度时）
```python
def middleNode_first(self, head):
    """
    偶数长度时返回第一个中点
    技巧：快指针先走一步
    """
    if not head or not head.next:
        return head
    
    slow = head
    fast = head.next  # 快指针先走一步
    
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    
    return slow
```

### 变体2：找到1/3处节点
```python
def oneThirdNode(self, head):
    """
    找到链表的1/3处节点
    快指针走3步，慢指针走1步
    """
    slow = fast = head
    
    while fast and fast.next and fast.next.next:
        slow = slow.next
        fast = fast.next.next.next
    
    return slow
```

### 变体3：找到3/4处节点
```python
def threeFourthNode(self, head):
    """
    找到链表的3/4处节点
    快指针走4步，慢指针走3步
    """
    slow = fast = head
    
    # 先让慢指针走两步，快指针走三步
    for _ in range(2):
        if not fast or not fast.next:
            return slow
        fast = fast.next
    
    # 然后快慢指针同步走
    while fast and fast.next:
        slow = slow.next
        fast = fast.next
    
    return slow
```

## 优化技巧

### 1. 减少变量
```python
def middleNode_compact(self, head):
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
    return slow
```

### 2. 使用生成器（高级）
```python
def middleNode_generator(self, head):
    """
    使用生成器实现，更Pythonic
    """
    def node_generator(node):
        while node:
            yield node
            node = node.next
    
    # 实际上还是需要快慢指针逻辑
    # 这里只是展示另一种思路
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    return slow
```

### 3. 异常处理
```python
def middleNode_safe(self, head):
    """
    添加异常处理的版本
    """
    try:
        slow = fast = head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        return slow
    except AttributeError:
        # 处理链表结构异常
        return None
```
