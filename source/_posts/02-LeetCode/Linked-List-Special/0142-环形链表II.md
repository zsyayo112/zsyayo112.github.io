# 0142. 环形链表II - 找到环起点的数学证明与算法实现

> 本文深入分析LeetCode第142题"环形链表II"，这是141题的进阶版本，不仅需要检测环，还要找到环的起点。包含完整的数学证明和多种解法。

## 题目描述

### 英文题目
Linked List Cycle II

### 中文题目
给定一个链表的头节点 `head` ，返回链表开始入环的第一个节点。如果链表无环，则返回 `null`。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始）。如果 `pos` 是 `-1`，则在该链表中没有环。

注意：`pos` 不作为参数进行传递，仅仅是为了标识链表的实际情况。

不允许修改链表。

### 示例
```
输入：head = [3,2,0,-4], pos = 1
输出：返回索引为1的节点
解释：链表中有一个环，其尾部连接到第二个节点。

输入：head = [1,2], pos = 0
输出：返回索引为0的节点
解释：链表中有一个环，其尾部连接到第一个节点。

输入：head = [1], pos = -1
输出：返回null
解释：链表中没有环。
```

### 进阶
你是否可以使用 O(1) 空间解决此题？

### 约束条件
- 链表中节点的数目范围在范围 `[0, 10^4]` 内
- `-10^5 <= Node.val <= 10^5`
- `pos` 的值为 `-1` 或者链表中的一个有效索引

## 解题思路

### 核心思想（Floyd算法扩展）
1. **第一阶段**：使用快慢指针判断是否有环（同141题）
2. **第二阶段**：如果快慢指针相遇，将一个指针移回head，两个指针以相同速度前进，再次相遇点即为环起点

### 算法步骤
1. 初始化 `slow = fast = head`
2. 使用快慢指针判断是否有环：
   - `slow` 每次走1步，`fast` 每次走2步
   - 如果 `fast` 或 `fast.next` 为 `None`，说明无环，返回 `None`
   - 如果 `slow == fast`，说明有环，进入第3步
3. 将一个指针移回head：
   - `slow = head`（或 `fast = head`）
   - 两个指针都以每次1步的速度前进
4. 当两个指针再次相遇时，所在节点即为环的起点

## 代码实现

### 标准解法（Floyd算法）
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        """
        找到环的起点 - Floyd算法扩展
        
        时间复杂度: O(n)
        空间复杂度: O(1)
        
        算法步骤:
        1. 快慢指针判断是否有环
        2. 如果有环，将一个指针移回head
        3. 两个指针同步前进，相遇点即为环起点
        """
        if not head or not head.next:
            return None
        
        # 第一阶段：判断是否有环
        slow = fast = head
        
        while fast and fast.next:
            slow = slow.next          # 慢指针走1步
            fast = fast.next.next     # 快指针走2步
            
            if slow == fast:          # 相遇，有环
                # 第二阶段：找到环起点
                slow = head           # 一个指针移回head
                
                while slow != fast:   # 同步前进直到相遇
                    slow = slow.next
                    fast = fast.next
                
                return slow           # 相遇点即为环起点
        
        return None  # 无环
```

### 哈希表方法（对比）
```python
class Solution:
    def detectCycle_hash(self, head: Optional[ListNode]) -> Optional[ListNode]:
        """
        哈希表方法 - 记录访问过的节点
        
        时间复杂度: O(n)
        空间复杂度: O(n)
        
        优点: 逻辑简单直观
        缺点: 需要额外空间
        """
        visited = set()
        curr = head
        
        while curr:
            if curr in visited:  # 如果节点已访问过，说明是环起点
                return curr
            visited.add(curr)    # 记录访问过的节点
            curr = curr.next
        
        return None  # 无环
```

## 详细分析

### Floyd算法数学证明

#### 符号定义
- `L`: 从head到环起点的距离（环外部分长度）
- `C`: 环的周长
- `k`: 快慢指针第一次相遇时，慢指针在环中走过的距离
- `m`: 快慢指针第一次相遇点距离环起点的距离

#### 第一阶段：快慢指针相遇
设相遇时：
- 慢指针走了 `L + k` 步
- 快指针走了 `L + k + mC` 步（多绕了m圈）

由于快指针速度是慢指针的2倍：
```
2(L + k) = L + k + mC
L + k = mC
L = mC - k
```

#### 第二阶段：找到环起点
从相遇点开始：
- 指针1从head开始走
- 指针2从相遇点开始走
- 两个指针都每次走1步

当指针1走到环起点时（走了L步）：
- 指针2从相遇点走了L步
- 由于 `L = mC - k`，指针2走了 `mC - k` 步
- 从相遇点（距离环起点k）走 `mC - k` 步后，位置为：
  ```
  起始位置: 距离环起点k
  走了: mC - k
  总距离: k + (mC - k) = mC
  ```
- 由于环的周长是C，走mC步相当于绕环m圈，回到环起点

因此两个指针在环起点相遇。

### 示例分析

#### 示例1：head = [3,2,0,-4], pos = 1
```
链表结构：
3 → 2 → 0 → -4
    ↑_______|
    
L = 1 (从3到2)
C = 3 (环：2→0→-4→2)

第一阶段：
slow: 3→2→0→-4
fast: 3→0→2→-4
在-4处相遇，k=2（从环起点2到相遇点-4的距离）

验证公式：L = mC - k
1 = m×3 - 2 ⇒ m=1

第二阶段：
slow回head(3)，fast在相遇点(-4)
同步走：
slow: 3→2
fast: -4→2
在2处相遇，即环起点
```

#### 示例2：head = [1,2], pos = 0
```
链表结构：
1 → 2
↑___|
    
L = 0 (head就是环起点)
C = 2 (环：1→2→1)

第一阶段：
slow: 1→2
fast: 1→2→1→2
在2处相遇，k=1

验证：L = mC - k
0 = m×2 - 1 ⇒ m=0.5（实际上m可以是任意整数，这里取最小）

第二阶段：
slow回head(1)，fast在相遇点(2)
同步走：
slow: 1
fast: 2→1
在1处相遇，即环起点
```

## 常见错误

### 错误1：忘记检查空链表
```python
# ❌ 错误：直接开始循环
slow = fast = head
while fast and fast.next:
    # ...
# 对于空链表，fast为None，循环不执行，返回None
# 正确但应该显式检查

# ✅ 更好：显式检查
if not head:
    return None
```

### 错误2：指针移动顺序错误
```python
# ❌ 错误：先判断相等再移动
while fast and fast.next:
    if slow == fast:  # 初始时slow==fast，错误进入第二阶段
        # ...
    slow = slow.next
    fast = fast.next.next

# ✅ 正确：先移动再判断
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
    if slow == fast:
        # ...
```

### 错误3：第二阶段指针选择错误
```python
# ❌ 错误：两个指针都移动
if slow == fast:
    slow = head
    fast = head  # 错误！应该保持fast在相遇点
    
# ✅ 正确：只移动一个指针
if slow == fast:
    slow = head  # 或 fast = head，但只能移动一个
    while slow != fast:
        slow = slow.next
        fast = fast.next
    return slow
```

### 错误4：循环条件不完整
```python
# ❌ 错误：可能访问None的next属性
while fast.next:
    slow = slow.next
    fast = fast.next.next

# ✅ 正确：双重检查
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
```

## 扩展应用

### 1. 计算环的长度
找到环起点后，固定一个指针，另一个指针继续走直到再次相遇。

```python
def cycleLength(self, head):
    """
    计算环的长度
    """
    meeting_point = self.detectCycle(head)
    if not meeting_point:
        return 0
    
    length = 1
    curr = meeting_point.next
    
    while curr != meeting_point:
        length += 1
        curr = curr.next
    
    return length
```

### 3. 找到链表的交点

## 算法变体

### 变体1：使用三个指针
```python
def detectCycle_three_pointers(self, head):
    """
    使用三个指针的版本，增加可靠性
    """
    if not head or not head.next or not head.next.next:
        return None
    
    p1 = head
    p2 = head.next
    p3 = head.next.next
    
    # 第一阶段：检测环
    while p3 and p3.next and p3.next.next:
        if p1 == p2 or p1 == p3 or p2 == p3:
            # 找到相遇点
            meeting = p1 if p1 == p2 else (p1 if p1 == p3 else p2)
            
            # 第二阶段：找环起点
            p1 = head
            while p1 != meeting:
                p1 = p1.next
                meeting = meeting.next
            return p1
        
        p1 = p1.next
        p2 = p2.next.next
        p3 = p3.next.next.next
    
    return None
```

def detectCycle_with_steps(self, head):
    """
    记录步数的版本，用于调试和理解
    """
    if not head:
        return None
    
    slow = fast = head
    steps = 0

    while fast and fast.next:

        fast = fast.next.next

            print(f"相遇在 {slow.val}，步数: {steps}")

            slow = head
            steps2 = 0

                slow = slow.next
                fast = fast.next
                steps2 += 1

            return slow
    
    return None

def detectCycle_optimized(self, head):
    """
    优化版本：提前检查常见情况
    """
    # 空链表或单节点无环
    if not head or not head.next:

    if head.next == head:
        return head
    
    # 三节点特殊情况
    if head.next.next == head:
        return head
    if head.next.next == head.next:
        return head.next
    
    slow = fast = head
    
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        
        if slow == fast:
            slow = head
            while slow != fast:
                slow = slow.next
                fast = fast.next
