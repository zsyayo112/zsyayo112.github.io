# 0019. 删除倒数第N个节点 - 快慢指针与虚拟头结点技巧详解

> 本文深入分析LeetCode第19题"删除倒数第N个节点"，重点讲解快慢指针技巧和虚拟头结点在处理边界条件时的关键作用。

## 题目描述

### 英文题目
Remove Nth Node From End of List

### 中文题目
给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

### 示例
```
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
解释：删除倒数第2个节点（值为4）

输入：head = [1], n = 1
输出：[]

输入：head = [1,2], n = 1
输出：[1]
```

### 进阶
你能尝试使用一趟扫描实现吗？

### 约束条件
- 链表中结点的数目为 `sz`
- `1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`

## 解题思路

### 核心思想
使用**快慢指针**技巧，让快指针先走n步，然后快慢指针同步前进，当快指针到达链表末尾时，慢指针正好指向要删除节点的前一个节点。

### 关键技巧
1. **虚拟头结点(dummy node)**：处理删除头结点的特殊情况
2. **快慢指针**：一趟扫描找到倒数第n个节点
3. **步长控制**：快指针先走n+1步（因为要找到前驱节点）

### 算法步骤
1. 创建虚拟头结点 `dummy`，连接到原链表
2. 初始化快慢指针都指向 `dummy`
3. 快指针先向前移动 `n+1` 步
4. 快慢指针同步向前移动，直到快指针为 `None`
5. 此时慢指针指向要删除节点的前一个节点
6. 执行删除：`slow.next = slow.next.next`
7. 返回 `dummy.next`

## 代码实现

### 标准解法（一趟扫描）
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        """
        删除倒数第n个节点 - 快慢指针+虚拟头结点
        
        时间复杂度: O(L)，其中L是链表长度
        空间复杂度: O(1)，只使用常数额外空间
        
        关键点:
        1. 使用虚拟头结点处理删除头结点的特殊情况
        2. 快指针先走n+1步（要找到前驱节点）
        3. 快慢指针同步走直到快指针为None
        """
        # 创建虚拟头结点
        dummy = ListNode(-1)
        dummy.next = head
        
        # 初始化快慢指针
        fast = slow = dummy
        
        # 快指针先走n+1步
        for _ in range(n + 1):
            fast = fast.next
        
        # 快慢指针同步前进
        while fast:
            fast = fast.next
            slow = slow.next
        
        # 删除slow.next（倒数第n个节点）
        slow.next = slow.next.next
        
        return dummy.next
```

### 无虚拟头结点版本（容易出错）
```python
class Solution:
    def removeNthFromEnd_no_dummy(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        """
        无虚拟头结点版本 - 需要特殊处理删除头结点的情况
        
        注意：这个版本容易出错，不推荐在实际中使用
        """
        # 特殊情况：链表为空
        if not head:
            return None
        
        # 快慢指针
        fast = slow = head
        
        # 快指针先走n步
        for _ in range(n):
            fast = fast.next
        
        # 如果fast为None，说明要删除的是头结点
        if not fast:
            return head.next
        
        # 快慢指针同步前进
        while fast.next:
            fast = fast.next
            slow = slow.next
        
        # 删除slow.next
        slow.next = slow.next.next
        
        return head
```

### 两趟扫描版本（基础）
```python
class Solution:
    def removeNthFromEnd_two_pass(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        """
        两趟扫描版本
        1. 第一趟计算链表长度
        2. 第二趟找到要删除的节点
        
        时间复杂度: O(2L) = O(L)
        空间复杂度: O(1)
        """
        # 计算链表长度
        length = 0
        curr = head
        while curr:
            length += 1
            curr = curr.next
        
        # 如果要删除的是头结点
        if n == length:
            return head.next
        
        # 找到要删除节点的前一个节点
        curr = head
        for _ in range(length - n - 1):
            curr = curr.next
        
        # 删除节点
        curr.next = curr.next.next
        
        return head
```

## 详细分析

### 虚拟头结点的关键作用

#### 为什么需要虚拟头结点？
考虑删除头结点的特殊情况：
```
链表: 1 → 2 → 3 → None, n=3（删除头结点1）

无虚拟头结点：
fast先走3步：fast = None
判断：if not fast: return head.next → 返回2
需要特殊处理头结点删除

有虚拟头结点：
dummy → 1 → 2 → 3 → None
fast从dummy开始走4步：fast = None
slow在dummy位置
删除：dummy.next = dummy.next.next → dummy → 2 → 3
返回dummy.next = 2
统一处理所有情况
```

#### 步数为什么是n+1？
因为我们要找到的是**要删除节点的前一个节点**，而不是要删除的节点本身。
```
链表: 1 → 2 → 3 → 4 → 5 → None, n=2（删除倒数第2个，即4）

dummy → 1 → 2 → 3 → 4 → 5 → None
fast从dummy开始走3步(n+1=3):
fast: dummy → 1 → 2 → 3

同步走：
fast: 3 → 4 → 5 → None
slow: dummy → 1 → 2 → 3

slow停在3，即要删除节点4的前一个节点
删除：3.next = 3.next.next → 3 → 5
```

### 快慢指针同步过程

#### 完整示例
```
链表: A → B → C → D → E → None, n=3（删除C）

初始化:
dummy → A → B → C → D → E → None
fast = slow = dummy

fast先走4步(n+1):
1. fast = A
2. fast = B
3. fast = C
4. fast = D

同步走:
1. fast = D → E, slow = dummy → A
2. fast = E → None, slow = A → B

此时:
fast = None
slow = B（C的前一个节点）

删除: B.next = B.next.next → B → D
结果: A → B → D → E → None
```

### 边界条件处理

#### 1. 删除头结点 (n == 链表长度)
```python
# 有虚拟头结点：自动处理
dummy → head → ...
fast走n+1步后为None
slow在dummy位置
删除dummy.next（即头结点）
```

#### 2. 删除尾结点 (n == 1)
```python
# 正常处理
fast先走2步
同步走到fast为None
slow指向倒数第2个节点
删除slow.next（尾结点）
```

#### 3. 链表只有一个节点
```python
# head = [1], n=1
dummy → 1 → None
fast走2步：fast = None
slow在dummy位置
删除：dummy.next = None
返回：dummy.next = None
```

#### 4. n等于链表长度-1
```python
# head = [1,2,3,4,5], n=4（删除倒数第4个，即2）
# 正常处理即可
```

## 常见错误

### 错误1：步数错误（走n步而不是n+1步）
```python
# ❌ 错误：快指针只走n步
for _ in range(n):  # 应该走n+1步
    fast = fast.next

# 结果：slow会指向要删除的节点，而不是前一个节点
# 无法执行删除操作（需要前驱节点）
```

### 错误2：忘记虚拟头结点（删除头结点出错）
```python
# ❌ 错误：无虚拟头结点，删除头结点时返回错误
if not fast:  # fast为None时
    return head.next  # 如果head.next也是None，返回None
    
# 但如果是删除中间节点，应该返回head
# 逻辑不一致，容易出错
```

### 错误3：循环条件错误
```python
# ❌ 错误：使用fast.next而不是fast
while fast.next:  # 如果fast已经是None，访问.next报错
    fast = fast.next
    slow = slow.next

# ✅ 正确：使用fast
while fast:
    fast = fast.next
    slow = slow.next
```

### 错误4：未检查n的有效性
```python
# ❌ 错误：假设n总是有效的
for _ in range(n + 1):
    fast = fast.next  # 如果n大于链表长度，这里会报错

# ✅ 正确：根据题目约束，n是有效的，但实际中应该检查
if n <= 0:
    return head
```

## 性能分析

### 时间复杂度对比

| 方法 | 时间复杂度 | 扫描次数 | 优点 | 缺点 |
|------|------------|----------|------|------|
| 快慢指针+虚拟头结点 | O(L) | 1趟 | 最优，一趟扫描 | 需要理解指针步数 |
| 两趟扫描 | O(2L) = O(L) | 2趟 | 逻辑简单 | 需要两次遍历 |
| 栈方法 | O(L) | 1趟（但需要额外空间） | 容易理解 | 空间复杂度O(L) |

### 空间复杂度对比

| 方法 | 空间复杂度 | 说明 |
|------|------------|------|
| 快慢指针+虚拟头结点 | O(1) | 只使用常数额外空间 |
| 两趟扫描 | O(1) | 只使用常数额外空间 |
| 栈方法 | O(L) | 需要栈存储所有节点 |

### 实际性能考虑
- **链表长度小(L<100)**：所有方法性能差异不大
- **链表长度大**：一趟扫描方法有明显优势
- **内存限制严格**：避免栈方法

## 优化技巧

### 1. 减少变量
```python
def removeNthFromEnd_compact(self, head, n):
    dummy = ListNode(0, head)
    fast = slow = dummy
    
    for _ in range(n + 1):
        fast = fast.next
    
    while fast:
        fast, slow = fast.next, slow.next
    
    slow.next = slow.next.next
    return dummy.next
```

### 2. 提前检查
```python
def removeNthFromEnd_checked(self, head, n):
    # 检查输入有效性
    if not head or n <= 0:
        return head
    
    dummy = ListNode(0, head)
    fast = slow = dummy
    
    # 先走n步，检查是否越界
    for _ in range(n):
        if not fast.next:  # n大于链表长度
            return head
        fast = fast.next
    
    # 再走1步（总共n+1步）
    fast = fast.next
    
    # 同步走
    while fast:
        fast = fast.next
        slow = slow.next
    
    slow.next = slow.next.next
    return dummy.next
```

### 3. 递归解法
```python
class Solution:
    def removeNthFromEnd_recursive(self, head, n):
        def remove(node):
            if not node:
                return 0, node
            
            i, node.next = remove(node.next)
            
            if i + 1 == n:
                return i + 1, node.next
            
            return i + 1, node
        
        _, head = remove(head)
        return head
```
