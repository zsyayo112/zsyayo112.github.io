# 0021. 合并两个有序链表 - 虚拟头结点技巧详解

> 本文详细分析LeetCode第21题"合并两个有序链表"，通过虚拟头结点技巧，实现简洁高效的链表合并算法。

## 题目描述

### 英文题目
Merge Two Sorted Lists

### 中文题目
将两个升序链表合并为一个新的**升序**链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

### 示例
```
输入：l1 = [1,2,4], l2 = [1,3,4]
输出：[1,1,2,3,4,4]

输入：l1 = [], l2 = []
输出：[]

输入：l1 = [], l2 = [0]
输出：[0]
```

### 约束条件
- 两个链表的节点数目范围是 `[0, 50]`
- `-100 <= Node.val <= 100`
- `l1` 和 `l2` 均按 **非递减顺序** 排列

## 解题思路

### 核心思想
使用**虚拟头结点(dummy node)**技巧，避免对空链表的特殊处理，统一合并逻辑。

### 算法步骤
1. 创建虚拟头结点 `dummy`
2. 使用指针 `curr` 指向当前合并位置
3. 比较两个链表当前节点的值，将较小的连接到 `curr.next`
4. 移动相应链表的指针
5. 重复步骤3-4直到某个链表为空
6. 将非空链表的剩余部分连接到结果链表
7. 返回 `dummy.next`

### 时间复杂度
- **时间复杂度**：O(n + m)，其中 n 和 m 分别是两个链表的长度
- **空间复杂度**：O(1)，只使用了常数级别的额外空间

## 代码实现

### 基础版本
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        # 创建虚拟头结点
        dummy = ListNode(-1)
        curr = dummy
        
        # 同时遍历两个链表
        while list1 and list2:
            if list1.val <= list2.val:
                curr.next = list1
                list1 = list1.next
            else:
                curr.next = list2
                list2 = list2.next
            curr = curr.next
        
        # 连接剩余部分
        curr.next = list1 if list1 else list2
        
        return dummy.next
```

### 优化版本（使用三元表达式）
```python
class Solution:
    def mergeTwoLists(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(-1)
        curr = dummy
        
        while l1 and l2:
            # 使用三元表达式简化代码
            if l1.val < l2.val:
                curr.next = l1
                l1 = l1.next
            else:
                curr.next = l2
                l2 = l2.next
            curr = curr.next
        
        # 更简洁的剩余部分连接
        curr.next = l1 or l2
        
        return dummy.next
```

### 递归版本
```python
class Solution:
    def mergeTwoLists(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        # 递归基：如果某个链表为空，直接返回另一个
        if not l1:
            return l2
        if not l2:
            return l1
        
        # 递归合并
        if l1.val < l2.val:
            l1.next = self.mergeTwoLists(l1.next, l2)
            return l1
        else:
            l2.next = self.mergeTwoLists(l1, l2.next)
            return l2
```

## 详细分析

### 虚拟头结点的作用
```
初始状态:
list1: 1 → 2 → 4 → None
list2: 1 → 3 → 4 → None

创建dummy: dummy → X
curr = dummy

第1步: list1.val(1) <= list2.val(1)
curr.next = list1 → 1
list1 = list1.next → 2
curr = curr.next → 1

第2步: list2.val(1) < list1.val(2)
curr.next = list2 → 1
list2 = list2.next → 3
curr = curr.next → 1

第3步: list1.val(2) < list2.val(3)
curr.next = list1 → 2
list1 = list1.next → 4
curr = curr.next → 2

... 以此类推
```

### 边界条件处理

#### 1. 空链表处理
```python
# 虚拟头结点自动处理空链表
dummy = ListNode(-1)  # 总是有效的
curr = dummy

# 即使list1和list2都为空，循环也不会执行
# 最后返回dummy.next，即None
```

#### 2. 单个链表先结束
```python
# 当某个链表先结束时，直接连接另一个链表的剩余部分
curr.next = list1 if list1 else list2

# 等价于:
if list1:
    curr.next = list1
else:
    curr.next = list2
```

### 性能对比

| 版本 | 时间复杂度 | 空间复杂度 | 优点 | 缺点 |
|------|------------|------------|------|------|
| 迭代+虚拟头结点 | O(n+m) | O(1) | 空间最优，逻辑清晰 | 需要额外节点 |
| 递归 | O(n+m) | O(n+m) | 代码简洁 | 栈空间开销大 |
| 无虚拟头结点 | O(n+m) | O(1) | 无额外节点 | 需要特殊处理空链表 |

## 常见错误

### 错误1：忘记移动指针
```python
# 错误：curr没有移动
curr.next = list1
list1 = list1.next
# 缺少: curr = curr.next
```

### 错误2：直接修改原链表头
```python
# 错误：丢失原链表头引用
result = list1  # 如果list1被修改，原链表头丢失
while list1 and list2:
    # ...
```

### 错误3：循环条件错误
```python
# 错误：使用or而不是and
while list1 or list2:  # 这样会导致访问None的val属性
    if list1.val <= list2.val:  # 如果某个为None，这里报错
```
