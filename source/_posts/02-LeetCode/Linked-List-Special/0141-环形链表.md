# 0141. 环形链表 - 快慢指针检测环与Floyd判圈算法详解

> 本文深入分析LeetCode第141题"环形链表"，详细讲解Floyd判圈算法（快慢指针）的原理、证明和实现，这是链表算法中的经典问题。

## 题目描述

### 英文题目
Linked List Cycle

### 中文题目
给你一个链表的头节点 `head` ，判断链表中是否有环。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始）。注意：`pos` 不作为参数进行传递。仅仅是为了标识链表的实际情况。

如果链表中存在环，则返回 `true` 。否则，返回 `false` 。

### 示例
```
输入：head = [3,2,0,-4], pos = 1
输出：true
解释：链表中有一个环，其尾部连接到第二个节点。

输入：head = [1,2], pos = 0
输出：true
解释：链表中有一个环，其尾部连接到第一个节点。

输入：head = [1], pos = -1
输出：false
解释：链表中没有环。
```

### 进阶
你能用 O(1)（即，常量）内存解决此问题吗？

### 约束条件
- 链表中节点的数目范围是 `[0, 10^4]`
- `-10^5 <= Node.val <= 10^5`
- `pos` 为 `-1` 或者链表中的一个有效索引

## 解题思路

### 核心思想
使用**Floyd判圈算法**（快慢指针）：
- 慢指针 `slow` 每次走1步
- 快指针 `fast` 每次走2步
- 如果链表中有环，快慢指针一定会相遇
- 如果链表中无环，快指针会先到达末尾

### 算法原理（Floyd's Cycle Detection Algorithm）
1. **初始化**：`slow = fast = head`
2. **移动指针**：
   - 慢指针每次移动1步：`slow = slow.next`
   - 快指针每次移动2步：`fast = fast.next.next`
3. **检测相遇**：
   - 如果 `fast == slow`，说明有环
   - 如果 `fast` 或 `fast.next` 为 `None`，说明无环
4. **数学证明**：见下文详细分析

## 代码实现

### 标准解法（快慢指针）
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def hasCycle(self, head: Optional[ListNode]) -> bool:
        """
        判断链表是否有环 - Floyd快慢指针算法
        
        时间复杂度: O(n)
        空间复杂度: O(1)
        
        算法步骤:
        1. 初始化快慢指针都指向头结点
        2. 快指针每次走2步，慢指针每次走1步
        3. 如果相遇则有环，如果快指针到达末尾则无环
        """
        if not head or not head.next:
            return False
        
        slow = head
        fast = head
        
        # 关键：双重检查，确保fast和fast.next都不为None
        while fast and fast.next:
            slow = slow.next          # 慢指针走1步
            fast = fast.next.next     # 快指针走2步
            
            if slow == fast:          # 相遇，有环
                return True
        
        return False  # 快指针到达末尾，无环
```

### 哈希表方法（对比）
```python
class Solution:
    def hasCycle_hash(self, head: Optional[ListNode]) -> bool:
        """
        哈希表方法 - 记录访问过的节点
        
        时间复杂度: O(n)
        空间复杂度: O(n)
        
        优点: 逻辑简单直观
        缺点: 需要额外空间存储节点
        """
        visited = set()
        curr = head
        
        while curr:
            if curr in visited:  # 如果节点已访问过，说明有环
                return True
            visited.add(curr)    # 记录访问过的节点
            curr = curr.next
        
        return False  # 到达末尾，无环
```

### 修改节点值方法（不推荐）
```python
class Solution:
    def hasCycle_modify(self, head: Optional[ListNode]) -> bool:

        修改节点值方法 - 遍历时修改节点值为特殊值
        
        注意: 这种方法会破坏原链表，不推荐在实际中使用
        仅作为算法思路的展示

        curr = head

            if curr.val == float('inf'):  # 如果遇到特殊值，说明有环
                return True
            curr.val = float('inf')       # 修改节点值为特殊值
            curr = curr.next
        
        return False
```

## 详细分析

### Floyd算法数学证明

#### 为什么快慢指针一定会相遇？
设：
- 环外部分长度为 `L`（从头结点到环入口）
- 环的周长为 `C`
- 相遇时慢指针走了 `k` 步
- 快指针走了 `2k` 步

**情况分析：**

1. **慢指针进入环时**：
   - 慢指针走了 `L` 步进入环
   - 快指针走了 `2L` 步，已经在环中走了 `L` 步
   - 快指针在环中领先慢指针 `L` 步

2. **在环中追击**：
   - 快指针每次比慢指针多走1步
   - 快指针需要追赶上慢指针的领先距离
   - 由于在环中，领先距离可以视为 `C - (L mod C)`
   - 快指针需要 `C - (L mod C)` 步追上慢指针

3. **总步数**：
   - 慢指针总步数：`L + [C - (L mod C)] < L + C`
   - 快指针总步数：`2L + 2[C - (L mod C)] < 2L + 2C`
   - 由于 `L < 10^4`, `C < 10^4`，总步数有限，一定会相遇

#### 相遇点分析
```
示例：head = [3,2,0,-4], pos = 1

链表结构：
3 → 2 → 0 → -4
    ↑_______|
    
L = 1 (从3到2)
C = 3 (环：2→0→-4→2)

慢指针进入环时：
slow在2，fast在0（fast领先1步）

追击过程：
第1步: slow=0, fast=-4 (fast领先2步)
第2步: slow=-4, fast=2 (fast领先0步，相遇！)
```

### 边界条件处理

#### 1. 空链表或单节点无环
```python
# 空链表
if not head:
    return False

# 单节点无环
if not head.next:
    return False
```

#### 2. 单节点有环
```python
# head = [1], pos = 0
# 结构：1 → 1 → 1 → ...
# 快慢指针都会指向同一个节点，但需要移动一次才能相遇
```

#### 3. 整个链表都是环
```python
# head = [1,2,3], pos = 0
# 结构：1 → 2 → 3 → 1 → ...
# 快慢指针从同一点出发，快指针会"套圈"追上慢指针
```

#### 4. 环很大或很小
```python
# 环很小：C=1
# 环很大：C接近10^4
# 算法都适用，时间复杂度O(L+C)
```

### 循环条件分析

#### 为什么是 `while fast and fast.next`？
```python
# 正确：双重检查
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next  # 需要fast.next存在
    
# 如果只检查fast
while fast:  # fast可能为None，但fast.next.next可能报错
    slow = slow.next
    fast = fast.next.next  # 如果fast.next为None，这里报错
    
# 如果只检查fast.next
while fast.next:  # 如果fast为None，访问.next报错
    slow = slow.next
    fast = fast.next.next
```

## 性能分析

### 时间复杂度对比

| 方法 | 时间复杂度 | 最坏情况 | 平均情况 | 优点 | 缺点 |
|------|------------|----------|----------|------|------|
| 快慢指针 | O(n) | O(L+C) | O(L+C/2) | 空间最优 | 需要理解算法 |
| 哈希表 | O(n) | O(n) | O(n) | 逻辑简单 | 空间O(n) |
| 修改节点值 | O(n) | O(n) | O(n) | 空间O(1) | 破坏原数据 |

### 空间复杂度对比

| 方法 | 空间复杂度 | 说明 |
|------|------------|------|
| 快慢指针 | O(1) | 只使用常数额外空间 |
| 哈希表 | O(n) | 需要存储所有节点 |
| 修改节点值 | O(1) | 只使用常数额外空间 |

### 实际性能考虑
- **链表长度小**：所有方法性能差异不大
- **链表长度大且有环**：快慢指针最优
- **链表长度大且无环**：快慢指针和哈希表相当
- **内存限制严格**：必须使用快慢指针

## 常见错误

### 错误1：初始化错误
```python
# ❌ 错误：fast从head.next开始
slow = head
fast = head.next  # 如果head为None，这里报错

# ✅ 正确：都从head开始
slow = fast = head
```

### 错误2：循环条件不完整
```python
# ❌ 错误：可能访问None的next属性
while fast.next:
    slow = slow.next
    fast = fast.next.next  # 如果fast.next为None，这里报错

# ✅ 正确：双重检查
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
```

### 错误3：忘记检查空链表
```python
# ❌ 错误：直接开始循环
slow = fast = head
while fast and fast.next:  # 如果head为None，fast为None，循环不执行
    # ...
# 对于空链表返回False，正确但应该显式检查

# ✅ 更好：显式检查
if not head:
    return False
```

### 错误4：指针移动顺序错误
```python
# ❌ 错误：先判断相等再移动
while fast and fast.next:
    if slow == fast:  # 初始时slow==fast，错误返回True
        return True
    slow = slow.next
    fast = fast.next.next

# ✅ 正确：先移动再判断
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
    if slow == fast:
        return True
```

def test_hasCycle():
    solution = Solution()
    
    # 测试用例1：有环
    # 创建链表: 3→2→0→-4→2(环)
    node1 = ListNode(3)

## 算法变体

### 变体1：龟兔赛跑不同速度
```python
def hasCycle_different_speed(self, head, slow_step=1, fast_step=2):
    """
    快慢指针不同速度的通用版本
    """
    if not head:
        return False
    
    slow = fast = head
    
    while fast:
        # 慢指针走slow_step步
        for _ in range(slow_step):
            if not slow:
                return False
            slow = slow.next
        
        # 快指针走fast_step步
        for _ in range(fast_step):
            if not fast:
                return False
            fast = fast.next
        
        if slow == fast:
            return True
    
    return False
```

### 变体2：使用三个指针
```python
def hasCycle_three_pointers(self, head):
    """
    使用三个指针，增加检测可靠性
    """
    if not head or not head.next or not head.next.next:
        return False
    
    p1 = head
    p2 = head.next
    p3 = head.next.next
    
    while p3 and p3.next and p3.next.next:
        if p1 == p2 or p1 == p3 or p2 == p3:
            return True
        
        p1 = p1.next
        p2 = p2.next.next
        p3 = p3.next.next.next
    
    return False
```

## 优化技巧

### 1. 提前检查
```python
def hasCycle_optimized(self, head):
    """
    优化版本：提前检查常见情况
    """
    # 空链表或单节点无环
    if not head or not head.next:
        return False
    
    # 双节点互相指向
    if head.next == head:
        return True
    
    slow = head
    fast = head.next
    
    while fast and fast.next:
        if slow == fast:
            return True
        slow = slow.next
        fast = fast.next.next
    
    return False
```

### 2. 减少比较次数
```python
def hasCycle_efficient(self, head):
    """
    减少比较次数的版本
    """
    if not head:
        return False
    
    slow = head
    fast = head
    
    while True:
        # 快指针移动
        if not fast or not fast.next:
            return False
        fast = fast.next.next
        
        # 慢指针移动
        slow = slow.next
        
        # 比较
        if slow == fast:
            return True
```

### 3. 使用异常处理
```python
def hasCycle_safe(self, head):
    """
    使用异常处理的健壮版本
    """
    try:
        slow = fast = head
        
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
            
            if slow == fast:
                return True
        
        return False
    except AttributeError:
        # 处理链表结构异常（如next指向无效内存）
        return False
```
