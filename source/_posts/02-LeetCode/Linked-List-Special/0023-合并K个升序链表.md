# 0023. 合并K个升序链表 - 堆优化与分治策略详解

> 本文深入分析LeetCode第23题"合并K个升序链表"，探讨两种高效解法：堆优化(O(N log k))和分治合并(O(N log k))，并对比各种方法的性能差异。

## 题目描述

### 英文题目
Merge k Sorted Lists

### 中文题目
给你一个链表数组，每个链表都已经按升序排列。请你将所有链表合并到一个升序链表中，返回合并后的链表。

### 示例
```
输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
解释：链表数组如下：
[
  1->4->5,
  1->3->4,
  2->6
]
将它们合并到一个有序链表中得到：
1->1->2->3->4->4->5->6

输入：lists = []
输出：[]

输入：lists = [[]]
输出：[]
```

### 约束条件
- `k == lists.length`
- `0 <= k <= 10^4`
- `0 <= lists[i].length <= 500`
- `-10^4 <= lists[i][j] <= 10^4`
- `lists[i]` 按 **升序** 排列
- `lists[i].length` 的总和不超过 `10^4`

## 解题思路

### 问题分析
这是21题"合并两个有序链表"的扩展，从合并2个链表扩展到合并k个链表。

### 三种主要解法
1. **顺序合并**：两两合并，时间复杂度O(kN)
2. **堆优化**：使用最小堆维护当前最小节点，时间复杂度O(N log k)
3. **分治合并**：类似归并排序，时间复杂度O(N log k)

## 代码实现

### 方法1：堆优化（推荐）
```python
import heapq
from typing import List, Optional

class Solution:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        """
        堆优化方法 - 时间复杂度O(N log k)，空间复杂度O(k)
        
        思路：
        1. 使用最小堆维护每个链表的当前最小节点
        2. 每次从堆中弹出最小值，连接到结果链表
        3. 将被弹出节点的下一个节点加入堆中
        
        参数:
            lists: 链表数组
            
        返回:
            合并后的链表头结点
        """
        # 创建虚拟头结点
        dummy = ListNode(-1)
        curr = dummy
        
        # 初始化最小堆
        heap = []
        
        # 将每个链表的头结点加入堆中
        for i, head in enumerate(lists):
            if head:
                # 使用三元组 (值, 索引, 节点)
                # 索引用于解决值相同时的比较问题
                heapq.heappush(heap, (head.val, i, head))
        
        # 不断从堆中取出最小值
        while heap:
            val, i, node = heapq.heappop(heap)
            curr.next = node
            curr = curr.next
            
            # 如果该节点还有下一个节点，加入堆中
            if node.next:
                heapq.heappush(heap, (node.next.val, i, node.next))
        
        return dummy.next
```

### 方法2：分治合并
```python
class Solution:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        """
        分治合并方法 - 时间复杂度O(N log k)，空间复杂度O(log k)
        
        思路：
        1. 将k个链表两两分组合并
        2. 重复步骤1直到只剩一个链表
        3. 类似归并排序的分治思想
        """
        if not lists:
            return None
        
        # 使用分治合并
        return self.merge(lists, 0, len(lists) - 1)
    
    def merge(self, lists: List[Optional[ListNode]], left: int, right: int) -> Optional[ListNode]:
        """
        递归合并区间[left, right]内的链表
        """
        if left == right:
            return lists[left]
        
        mid = left + (right - left) // 2
        l1 = self.merge(lists, left, mid)
        l2 = self.merge(lists, mid + 1, right)
        
        return self.mergeTwoLists(l1, l2)
    
    def mergeTwoLists(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        """
        合并两个有序链表（21题解法）
        """
        dummy = ListNode(-1)
        curr = dummy
        
        while l1 and l2:
            if l1.val <= l2.val:
                curr.next = l1
                l1 = l1.next
            else:
                curr.next = l2
                l2 = l2.next
            curr = curr.next
        
        curr.next = l1 if l1 else l2
        
        return dummy.next
```

### 方法3：顺序合并（基础）
```python
class Solution:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        """
        顺序合并方法 - 时间复杂度O(kN)，空间复杂度O(1)
        
        思路：
        1. 从第一个链表开始，依次与后面的链表合并
        2. 每次合并两个链表，结果再与下一个链表合并
        """
        if not lists:
            return None
        
        result = lists[0]
        
        for i in range(1, len(lists)):
            result = self.mergeTwoLists(result, lists[i])
        
        return result
    
    def mergeTwoLists(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        """合并两个有序链表"""
        dummy = ListNode(-1)
        curr = dummy
        
        while l1 and l2:
            if l1.val <= l2.val:
                curr.next = l1
                l1 = l1.next
            else:
                curr.next = l2
                l2 = l2.next
            curr = curr.next
        
        curr.next = l1 if l1 else l2
        
        return dummy.next
```

## 详细分析

### 堆优化方法详解

#### 为什么需要三元组？
```python
# 错误：直接比较节点对象
heapq.heappush(heap, (node.val, node))  # 当val相同时，比较node对象会报错

# 正确：添加索引作为第二比较键
heapq.heappush(heap, (node.val, i, node))  # 当val相同时，比较索引i
```

#### 堆操作流程
```
初始链表:
lists = [
    [1→4→5],
    [1→3→4],
    [2→6]
]

初始化堆:
heap = [(1,0,node1), (1,1,node2), (2,2,node3)]

第1次pop: (1,0,node1) → 连接1
push: node1.next = 4 → heap加入(4,0,node4)

第2次pop: (1,1,node2) → 连接1
push: node2.next = 3 → heap加入(3,1,node5)

第3次pop: (2,2,node3) → 连接2
push: node3.next = 6 → heap加入(6,2,node6)

第4次pop: (3,1,node5) → 连接3
push: node5.next = 4 → heap加入(4,1,node7)

... 以此类推
```

### 分治合并方法详解

#### 分治过程
```
lists = [A, B, C, D, E, F, G, H]

第1层分组: (A,B), (C,D), (E,F), (G,H)
第2层分组: (AB, CD), (EF, GH)
第3层分组: (ABCD, EFGH)
第4层合并: ABCDEFGH

合并次数: 每层合并k/2次，共log k层
总合并次数: (k/2) * log k ≈ N log k
```

#### 递归树
```
merge(0,7)
├── merge(0,3)
│   ├── merge(0,1)
│   │   ├── merge(0,0) → A
│   │   └── merge(1,1) → B
│   │   └── mergeTwoLists(A,B) → AB
│   └── merge(2,3)
│       ├── merge(2,2) → C
│       └── merge(3,3) → D
│       └── mergeTwoLists(C,D) → CD
│   └── mergeTwoLists(AB,CD) → ABCD
└── merge(4,7)
    ├── merge(4,5)
    │   ├── merge(4,4) → E
    │   └── merge(5,5) → F
    │   └── mergeTwoLists(E,F) → EF
    └── merge(6,7)
        ├── merge(6,6) → G
        └── merge(7,7) → H
        └── mergeTwoLists(G,H) → GH
    └── mergeTwoLists(EF,GH) → EFGH
└── mergeTwoLists(ABCD,EFGH) → ABCDEFGH
```

## 性能对比

### 时间复杂度分析

| 方法 | 时间复杂度 | 推导过程 |
|------|------------|----------|
| 顺序合并 | O(kN) | 第1次合并: N₁+N₂ ≈ 2N/k<br>第2次合并: (2N/k)+N₃ ≈ 3N/k<br>...<br>第k-1次合并: ((k-1)N/k)+Nₖ ≈ N<br>总计: N/k * (2+3+...+k) ≈ kN |
| 堆优化 | O(N log k) | 每个节点进出堆一次: N<br>堆操作: log k<br>总计: N log k |
| 分治合并 | O(N log k) | 每层合并所有节点: N<br>层数: log k<br>总计: N log k |

### 空间复杂度分析

| 方法 | 空间复杂度 | 说明 |
|------|------------|------|
| 顺序合并 | O(1) | 只使用常数空间 |
| 堆优化 | O(k) | 堆中最多存储k个节点 |
| 分治合并 | O(log k) | 递归调用栈深度 |

### 实际性能考虑

1. **k较小(k<10)**：顺序合并可能更快（常数因子小）
2. **k中等(10<k<100)**：堆优化表现良好
3. **k很大(k>100)**：分治合并的递归栈可能成为问题
4. **链表长度差异大**：堆优化自适应性强

## 常见错误

### 错误1：堆中节点比较问题
```python
# 错误：当val相同时，比较ListNode对象
heapq.heappush(heap, (node.val, node))  # TypeError

# 正确：添加索引
heapq.heappush(heap, (node.val, i, node))
```

### 错误2：忘记检查空链表
```python
# 错误：直接遍历lists
for head in lists:
    heapq.heappush(heap, (head.val, i, head))  # 如果head为None，报错

# 正确：检查空链表
if head:
    heapq.heappush(heap, (head.val, i, head))
```

### 错误3：分治合并的递归终止条件
```python
# 错误：缺少终止条件
def merge(self, lists, left, right):
    mid = (left + right) // 2
    l1 = self.merge(lists, left, mid)      # 无限递归！
    l2 = self.merge(lists, mid + 1, right)
    
# 正确：添加终止条件
def merge(self, lists, left, right):
    if left == right:                      # 终止条件
        return lists[left]
    # ...
```

### 3. 内存优化
```python
# 使用迭代代替递归（分治合并）
def mergeKLists_iterative(self, lists):
    if not lists:
        return None
    
    interval = 1
    n = len(lists)
    
    while interval < n:
        for i in range(0, n - interval, interval * 2):
            lists[i] = self.mergeTwoLists(lists[i], lists[i + interval])
        interval *= 2
    
    return lists[0]
```
