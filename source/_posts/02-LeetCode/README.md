## 算法分类体系

### 基础算法
- **排序算法**：快速排序、归并排序、堆排序
- **搜索算法**：二分查找、DFS、BFS
- **贪心算法**：区间调度、背包问题
- **动态规划**：背包、最长子序列、编辑距离

### 数据结构
- **数组与字符串**：双指针、滑动窗口
- **链表**：反转、环检测、合并
- **栈与队列**：单调栈、优先队列
- **哈希表**：设计、应用场景
- **树**：遍历、BST、AVL、Trie
- **图**：遍历、最短路径、最小生成树

### 高级算法
- **并查集**：连通性问题
- **位运算**：状态压缩、位操作技巧
- **数学**：数论、组合数学、概率
- **设计题**：LRU、LFU、数据流

## 解题方法论

### 四步解题法
1. **理解问题**：明确输入输出，分析约束条件
2. **设计算法**：选择合适的数据结构和算法
3. **编写代码**：实现算法，注意边界条件
4. **测试优化**：测试各种情况，优化时间和空间

### 思维模板
```python
# 通用解题框架
def solve_problem(input):
    # 1. 初始化数据结构
    data_structure = init_structure()
    
    # 2. 处理输入
    for item in input:
        process_item(item, data_structure)
    
    # 3. 计算结果
    result = calculate_result(data_structure)
    
    # 4. 返回结果
    return result
```

## 学习路径

### 初级阶段（1-2个月）
1. **掌握基础**：数组、字符串、链表、栈、队列
2. **练习简单题**：LeetCode Easy难度100题
3. **建立思维**：理解算法思想，掌握基本模板

### 中级阶段（3-6个月）
1. **深入数据结构**：树、图、哈希表、堆
2. **练习中等题**：LeetCode Medium难度150题
3. **专题突破**：重点攻克薄弱环节

### 高级阶段（6-12个月）
1. **掌握高级算法**：动态规划、贪心、回溯、分治
2. **练习困难题**：LeetCode Hard难度50题
3. **参加竞赛**：LeetCode周赛、双周赛
